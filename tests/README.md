## Demo YAML suite

Для первого знакомства с текущим KOT 3.0.0 используйте [учебную мастерскую](../examples/kot-workshop/README.md): там есть оба формата СППР, процессы, самостоятельные feature и руководство. Этот старый YAML-набор сохранён как отдельный пример и не должен смешиваться с рабочей областью мастерской.

Данной директория содержит небольшой демонстрационный набор YAML-исходников тестов, с которыми ведется работа в расширении `KOT for 1C`.

Сценарии искусственные и призваны продемонстрировать структуру тестов, принципы навигации, параметризации, вложенностей, IntelliSense, QuickFix и работу других функций расширения. Они не являются моделированием реальных бизнес процессов.

Что включено:

- `RegressionTests/yaml/Drive/DemoCases` с двумя главными сценариями, отображаемыми в списке Менеджера тестов;
- `.../Drive/Common`, `.../Drive/Sales`, и `.../Drive/Imports` с переиспользуемыми вложенными сценариями;
- Небольшой CSV файл для демонстрации использования приложений к тесту;
- `DemoEtalon` с результатом сборки `.feature` из `.yaml` исходников;
- Вложенные сценарии демонстрируют работу с параметрами, их значениями по умолчанию, их частичную замену и передачу параметров в несколько уровней вложенности.
