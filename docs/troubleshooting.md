# Если что-то не работает

Сначала определите этап: обнаружение теста, редактирование, компиляция, подключение или выполнение. Это помогает не перезагружать всё окружение из-за локальной проблемы.

| Симптом | Что проверить первым |
|---|---|
| Тест не виден в Менеджере тестов | Корень активного профиля, фильтры, группу и наличие настройки запуска у главного СППР-теста |
| Процесс есть в Библиотеке, но не в сборке | Не является ли он вложенным без настройки запуска |
| Собирается не ожидаемый набор | Отметки, активный профиль, теги/фильтры компилятора и выключение настройки запуска |
| Сборка устарела после изменения вложенного сценария | Это ожидаемо: пересоберите зависимые тесты |
| Run не доступен | Наличие результата сборки/JSON и подходящий вид исходника |
| Собранная feature запускает несколько сценариев | Они объединены компилятором в общий файл |
| F11 просит исполняемый шаг | Каретка на обычном шаге, сохранённый файл, ограничения Background/сложных конструкций и тип команды |
| YAML не проходит без сборки | Проба поддерживает ограниченный обычный шаг; используйте полную сборку и карту для конструкций СППР |
| Vanessa Ready, но шаг не выполняется | Подключён ли нужный клиент и выбрана ли нужная база |
| Vanessa State unavailable | Доступность процесса/endpoint, модальный диалог или ошибка в самой Vanessa; затем повторное соединение |
| Changes not applied у клиента | Локальная запись сохранена, но ещё отличается от работающего профиля Vanessa |
| Подсветка неполная | Фактический журнал сеанса, идентичность feature и ограничения истории MCP |
| Запись остановлена в Vanessa, но текста нет в KOT | `.45` не даёт отдельного безопасного чтения результата; проверьте текст в самой Vanessa |
| Шаги записаны не на том языке | Язык генератора Gherkin в реально запущенной Vanessa; язык новых файлов — другая настройка |
| Form Explorer пуст | Подключение клиента, активное окно и ошибка чтения; смена клиента сбрасывает старые данные |
| Элемент не даёт Vanessa steps | Возможность активировать элемент, его видимость, неоднозначное имя и доступный инструмент |
| Подсказки не знают свой BSL-шаг | Исходники библиотеки в доступном каталоге; одна EPF не индексируется |
| Перетаскивание не вставляет текст | Используйте явную команду «Вставить» |
| Свойства не переключаются | Закрепление булавкой и наличие незавершённого редактирования |
| Настройка не применяется | Область, доверие рабочей области, внешнее изменение, корректность значения |

## Собрать полезное сообщение об ошибке

Укажите версии KOT, VS Code, платформы 1С и Vanessa; формат исходника; точную команду; ожидаемый и фактический результат. Приложите минимальный пример и текст ошибки. Для выполнения полезны данные диагностической панели и соответствующий фрагмент журнала.

Проверьте вложения перед [публикацией issue](https://github.com/alexiosus/KOTfor1C/issues): автоматическая очистка текста не скрывает содержимое скриншотов и произвольных файлов.

Ошибки, возникающие внутри Vanessa, могут требовать исправления upstream. KOT не может гарантировать возможность отменить синхронный вызов или восстановить данные, которых API не возвращает.
