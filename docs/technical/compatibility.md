# Совместимость и известные ограничения

Документ описывает границы KOT **3.0.0**. Успешный автоматический тест расширения не подтверждает работу любой платформы 1С, компилятора или версии Vanessa.

| Компонент | Поддерживаемая граница |
|---|---|
| VS Code | 1.106 и новее по manifest; регрессии конкретных версий проверяются отдельно |
| Windows | Основной маршрут локальной компиляции, подготовки ИБ и запуска 1С |
| macOS/Linux | Редактор, документация, организация исходников и настройки; локальный runtime 1С не заявлен |
| СППР | Внешний совместимый компилятор, оба формата исходников и процессы; точные поля зависят от конфигурации |
| Vanessa | Каталоги по версии поставки; MCP-функции по реально объявленным инструментам |
| MCP `.45` | Проверенный контракт, а не обещание полного покрытия API |
| Multi-root | Ресурсные настройки учитывают папку; подготовка активного профиля использует один общий корень и предлагает отдельное окно для вторичной папки |
| Библиотеки | Feature/BSL-исходники индексируются; бинарная EPF не даёт полного каталога определений |

## Различия, которые влияют на работу

- Парный `scen.feature` — фрагмент СППР. Не переносите на него все требования самостоятельной feature.
- Проба шага YAML поддерживает ограниченный обычный шаг; сложные конструкции требуют компиляции.
- `SplitFeatureFiles` — доработка компилятора Drive. Проверяйте её наличие в вашей конфигурации.
- Устаревшая сборка может содержать прежние значения и библиотеки. Подтверждение запуска не делает её актуальной.
- Отмена ожидания не всегда прерывает синхронное действие Vanessa. Полная история и отдельные клиентские данные могут быть недоступны.
- При проблемах drag-and-drop используйте **Вставить** и файловые диалоги.
- На общих папках Parallels жёсткие ссылки могут не поддерживаться; преобразования используют проверяемое копирование. Навигация сохраняет доступное представление пути и не требует автоматически ослаблять UNC-политику VS Code.
