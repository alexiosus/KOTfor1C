# ИИ: данные и сохранённые отчёты

В KOT 3.1.0 удалён встроенный транспорт к OpenAI-совместимым API. KOT предоставляет внешнему агенту MCP-инструменты; подключение модели и её авторизация относятся к выбранному ИИ-клиенту. Область доступа, выполнение и политика правок описаны в [руководстве агента](../guides/ai-agent.md) и [API](agent-api.md).

## Результаты прежнего режима

Существующие описания сценариев сохраняются в метаданных и доступны в свойствах. Их удаление или миграция не требуется.

Сохранённые Markdown-отчёты остаются в каталогах configuration-diff-ai-reports и test-review-ai-reports внутри runtime. По умолчанию это .vscode/kot-runtime; другое место задаёт runtime.directory. Отдельные команды открывают файл для текущей ветки Git, сохраняя прежнюю нормализацию имени и суффикс хеша. В detached HEAD используется имя HEAD.

Для поиска отчёта конфигурации используется настроенная файловая выгрузка, для ревью — корень тестов. Наличие главной ветки или нового diff не требуется. Если файл или исходный каталог недоступен, новый отчёт не создаётся. Сохранённый отчёт сам по себе не подтверждает проверку текущих изменений.

Реализация совместимого просмотра: [savedAiReports.ts](../../src/savedAiReports.ts).

## Новые отчёты

Задачи, наблюдения, правки, прогоны и отчёты агента хранятся под agent/operations внутри runtime. Их можно открыть командой **Агент: открыть отчёт операции**. Статусы полного прогона, частичной проверки и непроведённых проверок различаются.
