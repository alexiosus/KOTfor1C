# Структура репозитория

Все руководства находятся в [docs](../README.md), примеры — в [examples](../../examples/README.md). Для первого знакомства откройте [учебную мастерскую](../../examples/kot-workshop/README.md). Ниже — карта каталогов для работы над самим расширением.

```text
KOTfor1C/
├── README.md                 Обзор и общее оглавление
├── CHANGELOG.md              Изменения по версиям
├── CONTRIBUTING.md           Правила работы над проектом
├── docs/
│   ├── README.md             Вход в пользовательское руководство
│   ├── guides/               Работа с отдельными возможностями
│   ├── technical/            Архитектура, контракты и разработка
│   ├── assets/               Скриншоты, видео и иллюстрации
│   │   ├── branding/         Логотип и постер проекта
│   │   └── archive/          Неиспользуемые исторические изображения
│   ├── ux/                   Макеты и прототипы интерфейса
│   ├── qa/                   Материалы ручной проверки
│   └── superpowers/          Спецификации, планы, аудиты и черновики issue
├── examples/
│   └── kot-workshop/         Учебный проект с упражнениями
├── src/                      TypeScript-код расширения
├── media/                    Интерфейсы webview: HTML, CSS и JavaScript
├── res/                      Ресурсы расширения, шаблоны и адаптеры 1С
├── syntaxes/                 Грамматика и настройки языка feature
├── l10n/                     Переводы сообщений
├── test/                     Автоматические тесты расширения
│   ├── fixtures/             Тестовые данные
│   └── helpers/              Общие вспомогательные средства тестов
├── tools/                    Проверки, генераторы и средства сборки
├── third-party/              Исходники и лицензии сторонних компонентов
├── artifacts/vsix/           Локальные пакеты VSIX, вне Git
```

## Куда добавлять файлы

| Файл | Место |
|---|---|
| Руководство для тестировщика | `docs/guides/`, ссылка из общего оглавления |
| Описание внутреннего контракта | `docs/technical/` |
| Скриншот или запись экрана | `docs/assets/`, описание в [галерее](../screenshots.md) |
| Новое учебное упражнение | `examples/kot-workshop/`, инструкция рядом с примерами |
| Проверка поведения расширения | `test/*.test.ts`, данные в `test/fixtures/` |
| Скрипт для разработчика | `tools/` или тематический подкаталог внутри него |
| Установочный пакет VSIX | `artifacts/vsix/` |

`test/` содержит проверки кода расширения. Сценарии 1С из `examples/` служат учебными проектами. Материалы в `docs/superpowers/` фиксируют этапы разработки; актуальное описание поведения находится в руководствах и справочниках.

В мастерской скачанные инструменты `tools/`, локальный компилятор в `build/`, служебный каталог `.vscode/kot-runtime/` и созданные при упражнениях библиотеки `step_definitions/` и `step_definitions-src/` остаются локальными: они исключены из Git и VSIX. В поставку входит исходный учебный шаг, из которого можно создать свою библиотеку.

## Что было перенесено

| Прежнее место | Текущее место |
|---|---|
| `documentation/` | `docs/` |
| `documentation/blocks/` | `docs/guides/` |
| Иллюстрации в корне `docs/` | `docs/assets/`, `branding/` и `archive/` |
| `language-configuration-feature.json` | `syntaxes/feature-language-configuration.json` |
| Локальные `*.vsix` в корне | `artifacts/vsix/` |

Ссылки внутри проекта и генераторы справочников используют новые пути. Список разделов документации 2.7.1 сохранён без изменений: проверка сопоставляет прежние пути с новыми и проверяет те же идентификаторы разделов. Внешние ссылки на `documentation/` текущей ветки нужно обновить; файлы в старых тегах Git остаются по прежним адресам.
