# Руководство KOT for 1C

Здесь описана работа с **KOT 3.0.0**. Начните с нужной задачи; устройство файлов и внутренние механизмы вынесены в [технический раздел](technical/README.md).

## Первые шаги

1. [Быстрый старт](QUICK_START.md) — попробовать редактор без 1С, подключить СППР или самостоятельные feature.
2. [Подготовка окружения](SETUP.md) — что необходимо для компиляции, выполнения и управления Vanessa.
3. [Знакомство с интерфейсом](interface.md) — где находятся панели и основные действия.
4. [Учебная мастерская](../examples/kot-workshop/README.md) — небольшие примеры и упражнения.
