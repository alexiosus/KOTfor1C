# Карта возможностей

Эта страница служит проверочным списком того, что можно изучить в KOT. Для первого знакомства достаточно [быстрого старта](QUICK_START.md).

| Направление | Возможности | Руководство |
|---|---|---|
| Первое открытие | Четыре маршрута мастера, чтение проекта, план изменений, продолжение позже, копия мастерской | [Мастер](guides/first-run-settings.md) |
| Настройки | 83 ключа, восемь разделов, поиск, области, наследование, сброс, черновик, конфликты, нативные пикеры | [Настройки](guides/first-run-settings.md) |
| Редактор | Шаги и вызовы, параметры, переменные, теги/директивы, поиск по смыслу через `!`, формат таблиц, F12, ссылки, ховеры, semantic-подсветка | [Редактор](guides/editor-and-intellisense.md) |
| Библиотека | Версионные шаги Vanessa, BSL-исходники, экспорты, СППР, процессы, категории, языки, поиск, избранное, предпросмотр | [Библиотека](guides/editor-and-intellisense.md) |
| Создание | Главный/вложенный сценарий и процесс, feature, экспорт и пользовательский шаг; defaults и серии номеров | [Создание](guides/scenario-creation.md) |
| Преобразования | YAML ↔ feature + meta; главный ↔ вложенный; вложенный ↔ экспортный, перенос поддерживаемых вызовов | [Форматы](guides/scenario-source-formats.md) |
| Свойства | Шапка, параметры, связи, теги, настройки запуска, сценарии feature, вложения, Save/Run/звезда/булавка | [Свойства](guides/scenario-properties-editor.md) |
| Организация | Группы, порядок, выбор набора, фильтры, прямые/косвенные зависимости, личное состояние | [Менеджер тестов](guides/test-manager.md) |
| Компиляция | Проверка профиля, процессы, варианты, изолированные части, отмена, отчёты, карты и актуальность | [Сборка](guides/build-and-vanessa-run.md) |
| Выполнение | Управляемая/существующая MCP-сессия, Run, F11, выделение, запуск с шага, точки останова, Stop/продолжение | [Vanessa](guides/vanessa-control.md) |
| Авторинг | Запись у каретки, шаги активного элемента, проверки всей формы, runtime-поиск и проверка синтаксиса | [Form Explorer](guides/form-explorer.md) |
| Переменные и диагностика | Авточтение, строковое изменение, локальное удаление, ошибки, журналы, снимки и ZIP | [Vanessa](guides/vanessa-control.md) |
| Окружение | Платформы, запуск/Конфигуратор, DT/CF, шаблоны, лаунчер, файловые базы и эталоны | [Базы](guides/infobase-manager.md) |
| Клиенты | Сохранённые/живые профили, пользователь/пароль/ключи, Add/Connect/Disconnect, Save to KOT | [Клиенты](guides/infobase-manager.md) |
| FirstLaunch | ZIP подготовленного каталога с версией конфигурации в поддерживаемых XML | [Сборка](guides/build-and-vanessa-run.md) |
| Командная работа | `.kot`, sidecar, каталоги, нумерация, Git и отделённые личные сведения | [Общие данные](guides/shared-project-library.md) |
| Вложения | Добавление, конфликт имён, вставка имени, переименование, удаление и MXL | [Файлы](guides/navigation-and-files.md) |
| AI | Описание сценария, отчёт по конфигурации, ревью тестов через выбранный сервис | [AI](guides/ai-description.md) |

Контекстные действия разобраны в [карте меню](context-menus.md); менее заметные возможности — в [практических маршрутах](everyday-workflows.md).

## Где возможностей пока недостаточно

MCP не обещает полный специализированный UI для всех инструментов, полную историю всех сценариев или дешёвую отмену любого запроса. Проба YAML не заменяет компилятор. Локальный runtime 1С на macOS/Linux не заявлен. Подробности собраны в [совместимости](technical/compatibility.md) и [матрице MCP](technical/execution-and-mcp.md).
