# Контекстные меню: действия рядом с тестом

Правый клик открывает действия для того места, где вы работаете. Меню редактора, строки Менеджера тестов и определения в Библиотеке решают разные задачи. Состав зависит от типа файла, строки под кареткой и готовности сборки.

![Актуальное подменю KOT на шаге парного scen.feature в Windows DevHost](assets/editor-context-menu.png)

## В тексте сценария: правый клик → KOT

Не нужно включать кнопки над строками, чтобы пользоваться этим меню.

| Раздел | Что искать | Когда полезно |
|---|---|---|
| Начало меню | Свойства, найти вызовы, избранное | Быстро перейти от текста к связанному объекту |
| **Работа с файлами** | Папка `files/`, MXL, показать файл в VS Code или системном проводнике | Найти вложение или файл результата |
| **Создать…** | Главный/вложенный сценарий, процесс, feature | Добавить новый тест из текущего рабочего места |
| **Редактирование** | Имя и код сценария, секции параметров/вызовов, шаги и настройки процесса, AI-описание | Изменить структуру и поддержать связи |
| Действия запуска | Запустить feature, один шаг, с шага, выделение | Выбрать нужный объём выполнения |
| **Выполнение и точки останова** | JSON, точка останова, список точек, проба YAML, шаг по карте сборки | Подготовить или проверить выполнение |
| **Запись и проверки формы** | Начать/остановить запись, получить шаги, проверки формы, **Преобразования…** | Получить текст из приложения или изменить способ хранения теста |
| **Логи и отслеживание запуска** | Привязать журнал к feature, переключить прогон, прекратить отслеживание, открыть прогон из log-файла | Следить за запуском, сделанным вне KOT |

Для перехода к определению используйте **F12** в любой позиции строки вызова. В собранной feature, если у шага нет собственного определения, F12 открывает строку исходника по карте компилятора, а при отсутствии соответствия — окружающий вложенный сценарий. [Навигация](guides/navigation-and-files.md).

Для **запуска с шага** поставьте каретку на исполняемую строку. Для **выполнения выделения** выделите шаги вместе с их таблицами или многострочным текстом. Пустая строка, шапка сценария и Background не равнозначны точке начала сценария.

Переименование имени и изменение кода — разные операции. Имя видит читатель, код участвует в идентификации СППР. Используйте штатное действие KOT, чтобы получить проверку и обновление поддерживаемых вызовов.

## В Менеджере тестов

Правый клик по строке главного сценария или процесса открывает его контекст:

- исходник, свойства, группа и настройка запуска;
- выполнение и открытие собранной feature;
- **Open JSON**: исходный JSON компилятора или итоговый JSON с дополнительными параметрами;
- журнал запуска и просмотр живого вывода, когда он доступен;
- переименование и удаление.

У процесса дополнительно доступны добавление и редактирование шагов. У группы — действия самой группы. Некоторые пункты отключены до сборки или во время операции; наведите на них, чтобы увидеть причину.

Меню **…** в заголовке панели относится ко всему проекту: параметры, платформы, настройки, создание, обслуживание и AI. Оно не заменяет меню отдельного теста.

## В Библиотеке

Откройте определение и его действия: переход к исходнику, вставка вызова, группа/категория, избранное, переименование и доступные преобразования. Не все действия применимы к встроенному шагу Vanessa: встроенный каталог и редактируемое определение проекта имеют разные источники.

У файлов и каталогов вложений есть собственное контекстное меню. Действия с вложением относятся к этому файлу, а не ко всей feature.

## В Информационных базах и переменных

Меню **…** строки базы группирует запуск, DT/CF, конфигурацию и управление. У клиента тестирования — действия его профиля. **Connect/Disconnect** относятся к выбранному клиенту, а **Save to KOT** сохраняет локальный профиль строки, известной только Vanessa.

Правый клик по переменной сеанса позволяет изменить строковое значение или удалить локальную переменную, если это поддерживается текущим контекстом.

## В Проводнике VS Code

Для feature доступны создание JSON запуска и запуск в Vanessa, для MXL — открытие в установленной программе работы с файлами 1С. Это меню файла; для выполнения отдельного шага откройте текст и используйте меню KOT в редакторе.
