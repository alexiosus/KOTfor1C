# Словарь KOT, СППР и Vanessa

Словарь помогает читать интерфейс и отличать сущности, названия которых похожи. Структурные поля YAML и API сохраняют исходные имена; перевод подписей не переименовывает файлы.

| Термин | Значение |
|---|---|
| Сценарий СППР | Описание действий с UID, параметрами и связями; требует компиляции для полного запуска |
| Главный сценарий | Сценарий с настройкой самостоятельного запуска |
| Вложенный сценарий | Повторно используемая часть другого сценария |
| Процесс СППР | Последовательность шагов сценариев и подпроцессов |
| Главный процесс | Процесс с настройкой самостоятельного запуска |
| Настройка запуска | Отдельный объект СППР с вариантом данных и привязкой к сценарию/процессу |
| Самостоятельная feature | Обычный тест Gherkin Vanessa, не являющийся исходником или результатом СППР |
| Экспортный сценарий | Вызываемое определение в feature-библиотеке Vanessa |
| Пользовательский шаг | Реализация шага в BSL-библиотеке |
| Параметр `[Имя]` | Значение, подставляемое при компиляции СППР |
| Переменная `$Имя$` | Значение контекста во время выполнения Vanessa |
| Сохранённый контекст `$$Имя$$` | Отдельная область переменных Vanessa, не параметр СППР |
| Компиляция / Build / Compile | Преобразование исходников СППР в feature и сопровождающие файлы |
| Выполнение / Run | Прохождение шагов в Vanessa |
| Менеджер тестов KOT | Панель VS Code для организации, сборки и запуска |
| Менеджер тестирования | Сеанс 1С с Vanessa, управляющий клиентами |
| Клиент тестирования | Сеанс проверяемой базы, которым управляет менеджер |
| Служебная ИБ | База для компилятора/менеджера, отличная от проверяемой базы |
| Эталонная база | Исходное состояние и параметры подготовки тестовой базы |
| Профиль KOT | Сохранённый набор параметров компиляции, дополнительных настроек Vanessa и GlobalVars |
| Профиль клиента | Именованное подключение Vanessa к базе с пользователем и параметрами запуска |
| Метаданные СППР | Шапка, параметры и связи в YAML исходника |
| Метаданные KOT | Группа, порядок, описание и категория в соседнем sidecar |
| Ответственный | Участник, отвечающий за сценарий; не определяет автоматически пользователя 1С |
| Автор серии | Владелец диапазона кодов; отдельное понятие нумерации |

Имена «главный/вложенный» уточняют роль в KOT. `legacy` и `native` остаются значениями настроек совместимости; в пользовательском объяснении им соответствуют «один YAML» и «feature + метаданные YAML».

Основные источники терминов: [руководство СППР](https://its.1c.ru/db/sppr2doc) и [документация Vanessa](https://pr-mex.github.io/vanessa-automation/dev/). Точный поддерживаемый формат дополнительно определяется шаблонами и парсерами KOT.
