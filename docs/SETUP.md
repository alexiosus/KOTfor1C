# Подготовка KOT и окружения 1С

Настраивайте только нужный этап. Для редактора не требуется служебная база, для обычной feature не нужен компилятор СППР, а AI подключается независимо от выполнения тестов.

<a id="1-обязательные-зависимости"></a>

## Требования по задачам

| Задача | Что подготовить |
|---|---|
| Редактор, Библиотека, свойства | VS Code 1.106+; расширение KOT; исходники тестов |
| Компиляция СППР | Windows; платформа 1С; совместимая обработка компилятора; параметры компиляции; при необходимости каталог эталонных баз |
| Выполнение Vanessa | Windows; платформа 1С; распакованная Vanessa Automation; отдельная тестовая база |
| Управление по MCP | Совместимые инструменты Vanessa и клиентский MCP devkit в менеджере тестирования |
| Статические подсказки формы | Дополнительно — файловая выгрузка конфигурации, если требуется обогащение метаданных |
| MXL | Установленная программа работы с файлами 1С |
| AI | Настройки вашего OpenAI-совместимого API |

На macOS/Linux доступны подготовка исходников и функции редактора. Локальная подготовка и запуск 1С в KOT рассчитаны на Windows.

## Настроить проект мастером

Откройте **KOT: Настроить проект**. Поиск читает файлы; применение выполняется только на итоговом шаге. Укажите фактические каталоги тестов и библиотек. Для новых профилей мастер предложит найденные корни, существующие профили не перезаписывает.

Кнопка **Обзор…** выбирает файл или папку. Внутри проекта путь по возможности сохраняется относительно него. У компилятора СППР выберите файл внутри проекта: этот путь используется как проектный.

В multi-root обычные настройки имеют выбор папки и области. Подготовка профиля сборки для вторичной папки предлагает отдельное окно, поскольку активный профиль пока управляет общим корнем поиска тестов.

## Подготовить компилятор СППР

1. Откройте вашу конфигурацию СППР в Конфигураторе.
2. Сохраните обработку **СборкаТекстовСценариев** в отдельный `.epf` внутри проекта, например `build/BuildScenarioBDD.epf`.
3. Выберите обработку в KOT. Расширение не поставляет и не заменяет вашу версию компилятора.
4. Откройте **Параметры сборки и запуска**: проверьте корни исходников, каталог результата, файл настроек эталонных баз и остальные обязательные значения.

Параметры конкретной конфигурации могут отличаться. Например, `SplitFeatureFiles` относится к доработке Drive, а не ко всем версиям СППР. [Контракт компилятора](technical/compiler.md).

Проверьте [таблицу обязательных полей](guides/parameters-manager.md#минимальная-проверка-сппр): требования `VanessaFolder`/launch-базы зависят от `CreateJson`, а `ModelDBSettings` обязателен при `AuthCompile=true`. Справка поставщика — [параметры обработки на ИТС](https://its.1c.ru/db/sppr2doc#content:124:hdoc); доступ к содержимому может требовать учётной записи ИТС.

<a id="37-vanessa-automation-launch"></a>

## Подготовить Vanessa

Укажите `vanessa-automation.epf` из распакованной поставки. Соседние исходники и `docs/Changelog.md` позволяют KOT определить версию каталога шагов и прочитать доступные параметры.

**Подключить Vanessa** может подготовить собственный сеанс на базе служебной ИБ KOT: проверить компоненты, запустить менеджер и дождаться MCP. Devkit может уже находиться в поставляемом DT; для прежней служебной базы предусмотрена однократная подготовка. На новом компьютере 1С может запросить установку нативной компоненты — наличие DT ещё не означает готовое соединение.

При подключении к существующему сеансу его база не переустанавливается. Адрес endpoint нужен, если автоматическое обнаружение не нашло подходящий локальный сеанс. Настройки соединения находятся в меню Менеджера тестов.

Подключение менеджера не означает подключение тестового клиента. Выберите нужную базу и профиль клиента в [Информационных базах](guides/infobase-manager.md).

Состав параметров запуска описывает [официальный справочник VAParams](https://pr-mex.github.io/vanessa-automation/dev/JsonParams/JsonParamsRU/). Он относится к Vanessa; возможность применить параметр к уже открытому MCP-сеансу — отдельный вопрос.

## Подключить дополнительные инструменты

Для AI используйте [согласованный пример вашего сервиса](guides/ai-connections.md), затем проверьте подключение на учебном сценарии. Для MXL установите [программу работы с файлами 1С](https://v8.1c.ru/static/1s-predpriyatie-rabota-s-faylami/) и укажите `paths.fileWorkshopExe`. Подготовка этих инструментов не является условием редактирования обычного теста.

## Разделить базы по назначению

- **Служебная ИБ** запускает компилятор и/или менеджер тестирования.
- **Тестовая ИБ** содержит проверяемое приложение и данные; её открывает клиент тестирования.
- **Эталонное состояние** — источник восстановления тестовой ИБ, например DT и профили пользователей.

Проверьте целевую базу и источник перед восстановлением. KOT показывает подтверждение для разрушительных операций.

## Проверить готовность

Откройте сохранённую feature и выполните простой безопасный шаг в тестовой базе. Убедитесь, что Vanessa подключена, выбран нужный клиент и язык генератора Gherkin совпадает с ожидаемым. Полный запуск дополнительно использует параметры запуска теста; различия с активным менеджером могут потребовать отдельного решения.

Если подготовку отменили, редактор остаётся готовым, а мастер предлагает повторить подключение Vanessa. [Решение проблем](troubleshooting.md) · [Настройки](guides/first-run-settings.md) · [Совместимость MCP](technical/execution-and-mcp.md).
