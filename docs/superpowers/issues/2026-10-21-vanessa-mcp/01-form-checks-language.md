# [MCP] get_form_analysis: Gherkin-проверка формы не учитывает язык генератора

Тип: **Ошибка**.

Проверенная версия: **Vanessa Automation 1.2.043.45**, исходники commit `a9625b83adfe0612da2adf750d82ca7993d73a70`. Новейший develop в рамках этого черновика не проверен; перед публикацией стоит проверить воспроизведение на актуальной версии.

## Задача

В интерфейсе Vanessa генерация проверки формы переводит результат согласно `ЯзыкГенератораGherkin`. MCP возвращает русский текст при `ЯзыкГенератораGherkin=en`, даже когда подсказки исследователя формы уже английские.

## Воспроизведение

1. Запустить Vanessa 1.2.043.45 с подключённым тест-клиентом и генератором Gherkin `en`.
2. Открыть форму с обычными полями.
3. Вызвать `get_form_analysis` с `{"format":"gherkin"}`; отдельно повторить с `{"format":"full"}`.
4. Сравнить раздел Gherkin с результатом штатной генерации проверки формы.

## Ожидаемое и фактическое поведение

Ожидается единый язык генерации через UI и MCP. Фактически MCP вызывает `ПолучитьИзмененияФормыGherkin()` и читает `СгенерированныйСценарий`, пропуская `СделатьПереводСгенерированногоТекстаGherkin()`. В UI этот перевод вызывается.

## Предложение

Вызывать штатный перевод перед возвратом сгенерированного Gherkin в обоих форматах. Значения полей, таблиц и пользовательские литералы не переводить. Проверить `ru/en` на одной форме.
