# [MCP] Регистрация инструментов при запуске обращается к неинициализированной VanessaExt.НайтиФайлы

Тип: **Ошибка**.

Проверенная версия: **Vanessa Automation 1.2.043.45**, исходники commit `a9625b83adfe0612da2adf750d82ca7993d73a70`. Новейший develop в рамках этого черновика не проверен; перед публикацией стоит проверить воспроизведение на актуальной версии.

## Задача

При новом MCP-запуске Vanessa .45 с включённым поиском файлов через VanessaExt регистрация инструментов может завершиться исключением «Значение не является значением объектного типа (НайтиФайлы)». После этого MCP недоступен.

## Воспроизведение

1. Включить использование VanessaExt и `ПоискФайловСПомощьюКомпонентыVanessaExt=true` в VAParams.
2. Запустить новый менеджер с MCP и библиотеками EPF; компонент ещё не подключён к моменту регистрации шагов.
3. Наблюдать стек: Form(19115) → 42501 → 42479 → 22490.
4. При отключении только поиска файлов через VanessaExt тот же запуск проходит инициализацию MCP без этого исключения.

## Ожидаемое и фактическое поведение

Ожидается регистрация после успешной инициализации компоненты либо штатный fallback поиска. Фактически объект `ВнешняяКомпонентаДляСкриншотов` не готов, а вызывается его `НайтиФайлы`.

## Предложение

Проверять готовность объекта, упорядочить инициализацию и регистрацию либо использовать штатный поиск 1С до готовности VanessaExt. Не отключать весь MCP и не терять остальные функции компоненты из-за этой гонки.
