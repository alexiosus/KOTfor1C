# [MCP] Чтение текущего содержимого таблицы формы

Тип: **Расширение API**.

Проверенная версия: **Vanessa Automation 1.2.043.45**, исходники commit `a9625b83adfe0612da2adf750d82ca7993d73a70`. Новейший develop в рамках этого черновика не проверен; перед публикацией стоит проверить воспроизведение на актуальной версии.

## Задача

При работе с приложением через MCP нужно читать текущее содержимое таблицы открытой формы: колонки, строки и значения ячеек. Например, проверить результат заполнения табличной части документа до записи, понять результат отбора в списке или определить строку для следующего действия.

Нужны данные в том виде, в котором они представлены в клиенте, с учётом текущих отборов, сортировки и ещё не сохранённых изменений. Чтение объекта или запрос к БД не заменяют эту операцию. Получения только выделенных строк также недостаточно, если требуется изучить содержимое таблицы целиком или его доступную часть.

## Воспроизведение

1. Подключить тест-клиент и открыть форму с таблицей из нескольких строк, например табличной частью документа.
2. Изменить значение ячейки, завершить редактирование ячейки, но не записывать документ. Выделить только одну строку.
3. Запросить `get_form_analysis` с `format=elements` и `only_table`, указав имя таблицы. Ответ описывает структуру элементов, но не предоставляет полный набор строк с ячейками.
4. Вызвать `manage_form_elements` с `action=get_selected_rows` и именем таблицы. Сравнить ответ с остальным содержимым таблицы: он относится к выделенным строкам.
5. Проверить возможность прочитать невыделенные строки и изменённое значение без изменения текущего выделения. Запрос `get_table_data` к данным объекта/БД не использовать как эквивалент текущего содержимого формы.

## Ожидаемое и фактическое поведение

**Ожидается:** read-only запрос возвращает строки и значения ячеек указанной таблицы открытой формы, а также сведения о текущей и выделенных строках. Запрос не меняет выделение, фокус, порядок строк или состояние редактирования.

**Фактически:** в проверенном API есть чтение структуры таблицы и выделенных строк, но не найден запрос полного текущего содержимого UI-таблицы с явными границами результата. Данные выделения или объекта/БД нельзя считать её полным состоянием.

## Предложение

Добавить отдельный инструмент либо read-only действие для чтения таблицы формы:

- Выбор таблицы по `table_name`.
- Имена и заголовки колонок, значения и представления ячеек, порядок строк согласно текущему состоянию формы.
- Сведения о текущей и выделенных строках, чтобы результат можно было использовать для последующего действия.
- Ограничение объёма и постраничное чтение, например `offset/limit` либо continuation token.
- Явный признак неполного ответа и описание области покрытия: все доступные строки, загруженная часть или только видимая область.

Если TestClient не позволяет прочитать все строки без прокрутки или изменения состояния, это ограничение должно быть отражено в ответе. Частичный результат не должен выглядеть как полный снимок таблицы. Для изменяемых таблиц полезна версия снимка либо иной способ обнаружить смену данных между страницами.
