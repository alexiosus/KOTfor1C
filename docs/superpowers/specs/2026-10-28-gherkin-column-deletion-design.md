# Удаление столбцов Gherkin-таблиц

Пользователь выбрал автоматическое удаление столбца при удалении целой ячейки
первой строки вместе с одним разделителем `|`. Очистка названия без удаления
разделителя оставляет столбец. Поведение одинаково для YAML, СППР feature + meta
и самостоятельных feature-файлов.

## Варианты

- Выбран: распространять структурное удаление в шапке на строки этой таблицы.
- Альтернатива: отдельная команда контекстного меню; требует дополнительного действия.

## Границы поведения

- Реагировать на одно удаление в активном редакторе, только в первой строке
  полностью сформированной прямоугольной таблицы с хотя бы одной строкой данных
  и двумя столбцами. Удаление всей таблицы остаётся обычным редактированием текста.
- Удалять соответствующие ячейки остальных строк; сохранять другие значения,
  экранированные `\|`, отступы и окончания строк.
- Изменения обратимы вместе с исходным удалением. Undo/Redo не запускают новое удаление.
- Замена текста, удаление части заголовка, нескольких строк или только разделителя
  между непустыми ячейками не считаются удалением столбца.
- Не изменять таблицеподобный текст в комментариях, docstring и YAML-метаданных.
- При неоднозначном удалении или конкурентной правке не угадывать содержимое.
- Выравнивание не дополняет незавершённые таблицы или строки с разным числом ячеек;
  после завершения редактирования обычное выравнивание возобновляется.

## Реализация

Чистая функция строит диапазоны удаления по предыдущему тексту. Обработчик VS Code
хранит предыдущую версию открытого документа, ограничивает YAML полем `ТекстСценария`
и применяет правки через активный редактор без дополнительных границ Undo.
