# Профили компиляции и запуска по проектам

Пользователь выбрал отдельное хранение профилей каждого проекта. Открытие мастерской не должно наследовать библиотеки, GlobalVars и выбранный профиль 1cDrive.

## Решение

- Идентичность проекта — URI первой корневой папки, совпадающий при открытии папки напрямую и через `.code-workspace`. Профили и активный выбор сохраняются в отдельном ключе SecretStorage. Два разных проекта не перезаписывают настройки друг друга. Окно без папки использует отдельный ключ.
- Старый общий ключ остаётся нетронутым. «Импортировать прежний общий профиль» копирует явно выбранный профиль в текущий проект с новым ID. Все три части профиля переносятся вместе; дальнейшие изменения копии независимы.
- Новый проект получает чистый профиль. Новый профиль мастера получает стандартные параметры Vanessa и пустые GlobalVars; явное дублирование сохраняет прежнее поведение копирования.
- Необязательный `.kot/parameter-profiles.json` задаёт начальные профили для проекта в существующем формате v5. Он читается только при отсутствии локально сохранённых профилей; редактирование через UI не изменяет этот файл. Мастерская поставляет такой файл: относительные корни, `Libraries=libraries`, каталог библиотек Vanessa, язык `en`, учебные GlobalVars, `CreateJson=false`.
- Мастер настройки сохраняет находящиеся внутри проекта пути относительно корня, внешние пути остаются абсолютными. Настройки установленной платформы, компилятора и Vanessa продолжают использовать существующие настройки VS Code.
- Состояние уже работающей Vanessa и ограничения загрузки JSON через MCP не меняются.

## Рассмотренные варианты

Только отдельный активный выбор дешевле, но оставляет общие изменяемые профили. Выбрана полная изоляция данных по проекту. Автоматический импорт общего профиля отклонён: он снова перенесёт библиотеки 1cDrive в мастерскую.

## Проверка

Регрессии: два проекта и восстановление выбора; наследование/сохранность старого общего ключа; явный импорт и его отмена; изоляция трёх частей профиля; стартовые настройки мастерской и сохранённые правки; некорректный стартовый файл; относительные пути и внешние библиотеки. Затем `npm run check`, `npm run compile`, `npm run verify:demo`, `npm run docs:check`.
