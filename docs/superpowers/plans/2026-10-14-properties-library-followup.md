# Properties и общая библиотека — продолжение 2026-10-14

Реализовано в текущем рабочем дереве:

- Files как отдельная вкладка со счётчиком, drop во всей панели.
- Личное перетаскивание групп отдельно от общего порядка элементов; main/process/standalone и согласованное отображение Library.
- Диагностические сообщения фаз только при Advanced Logging, одинаковые payload артефактов не дублируются.
- Шапка Properties с переносом названия; Open/Copy path вместо текста пути, навигация без сохранения и повторной загрузки связанных настроек.
- Двусторонний фейд и прокрутка, скрытые действия освобождают место; нативные поля сохраняют фокус/редактирование.
- FoldingRangeProvider: единая шапка перед телом сценария или шагами процесса, без изменений YAML.
- Структура менеджеров: действия списка баз в его заголовке, действия подготовки в меню выбранной базы; текущая форма внутри дерева; свойства выбранного элемента в строках; пояснения выбранного параметра в отдельной области. Общий модуль overflow для трёх менеджеров.
- Проверка поднабора YAML компилятора, недостающие опциональные поля, нативные типы и предупреждение о лимите 100 сочетаний.

Аудиты compiler-support и vanessa-debug-control фиксируют оставшиеся границы обработки и предлагаемый интерфейс отладки. Настройка наборов клиентов и MCP-команды пока исследованы, не реализованы. EPF/1С и внешний корпус Drive не изменялись.

Проверка: targeted tests и общий npm run vscode:prepublish; актуальный полный результат — в отчёте выполнения текущего запроса.
