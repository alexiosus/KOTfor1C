# Совместимость редактора KOT с компилятором YAML

Пользователь поручил исправить все шесть расхождений из сравнения исходников. Работа выполняется в текущем checkout с сохранением существующих изменений; компилятор в Downloads/BDD используется как источник грамматики и не изменяется.

1. Общий сканер тела сценария: комментарии, многострочные строки, отдельные RU/EN/препроцессорные блоки. Единый стек проверяет порядок закрытия и веток, язык и повторные ветки. Диагностика, подсказки, подсветка и автозаполнение используют тот же сканер.
2. Препроцессор: отдельные подсказки #Если/#ИначеЕсли/#Иначе/#КонецЕсли, проверка структуры выражения без выполнения произвольного BSL. Вычисление выражения и выбор ветки остаются обязанностью внешней обработки 1С.
3. Возвратные параметры: разбор Возврат/Return и как/as, проверка имени в вызванном сценарии, подсказки. Return подставляет в child параметр имя переменной Vanessa, куда child сохраняет результат. Alias — literal имя runtime-переменной, не ссылка на параметр родительской шапки. Родитель читает результат через $Alias$.
4. Табличные параметры: сохранять тип и многострочный default; вставлять через пустое присвоение и таблицу. Разбирать строки таблицы между параметрами; автозаполнение и выравнивание сохраняют таблицы и возвраты.
5. Варианты: разделение значений по неэкранированному ;, декартово число комбинаций и ограниченный предпросмотр без материализации всего произведения. Показывать в существующих inlay hints шапки.
6. Регрессионные проверки существующих completion/Library/hover/YAML edits, локализация и документация. Затем npm run check, npm run compile и независимое ревью.

Критичные проверки: перекрёстные блоки; смешение языков; препроцессор внутри runtime блока; шаги/скобки внутри /*…*/ и docstring; возврат с alias; два параметра вокруг таблицы; CRLF; экранированный ; и пустые значения; многомиллионное произведение без чрезмерных затрат памяти.

Реализованы все пункты. При перезаполнении сохраняется исходная запись default (включая legacy escapes и literal rows); новые блоки используют только `|`, который распознаёт reader внешней обработки. Многострочные строковые defaults ребёнка остаются неявными, defaults родителя передаются ссылкой. Предпросмотр вариантов декодирует только escapes компилятора. Независимое ревью подтвердило изменения; интеграционные регрессии сохранения default и предпросмотра прошли (13/13).
