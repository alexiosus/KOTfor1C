# User-step Libraries Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Управлять EPF-библиотеками из KOT и предлагать только шаги актуальных сборок.

**Architecture:** Модуль состояния сопоставляет проект обработки и EPF по отпечаткам содержимого. Общий индекс передаёт это состояние подсказкам и интерфейсам; действия проверяют его повторно. Выгрузка повторно использует зависимости запуска Конфигуратора.

**Tech Stack:** TypeScript, Node.js, VS Code webviews, Конфигуратор 1С.

**Spec:** `docs/superpowers/specs/2026-10-28-user-step-libraries-design.md`

## Global Constraints

- Обе версии Библиотеки; локализация ru/en; без новых зависимостей.
- Изменённые исходники блокируют шаги до успешной пересборки.
- Чужие рабочие изменения и готовые исходники не перезаписывать.
- Выполнение в текущем сеансе; фиксация коммита не запрошена.

## Review Focus

- Старая строка Библиотеки не должна позволять вставить уже устаревший шаг.
- Кэш индекса и событие замены EPF не должны сохранять прежнюю доступность.
- Неудачная или отменённая операция не должна уничтожать предыдущие файлы.
- Изменения исходников во время сборки не должны получить отметку актуальной сборки.
- Отдельный BSL и бинарная библиотека без исходников должны иметь доступный дальнейший путь.
