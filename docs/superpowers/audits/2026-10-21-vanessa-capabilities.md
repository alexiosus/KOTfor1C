# Возможности KOT и ограничения MCP Vanessa

Состояние реализации на 2026-10-21. Проверяемый upstream-контракт — Vanessa Automation **1.2.043.45**, commit `a9625b83adfe0612da2adf750d82ca7993d73a70`, локальные исходники `Forms/MCPVA`, `Forms/ИсследовательФормы`, `Forms/КлиентТестирования`; отмена задач дополнительно сверена с client-mcp-devkit 0.6.6. Это не утверждение о текущем develop или произвольном выбранном EPF. Инструменты доступны только при подходящей объявленной схеме текущего MCP-сеанса.

## Реализовано

| Область | Что доступно | Граница |
|---|---|---|
| Выполнение | F11, выделенные обычные шаги, YAML до сборки, запуск с выбранного шага, полный запуск, Stop и продолжение после подтверждённой точки | Сложные конструкции СППР требуют сборки/карты; Stop не сохраняет произвольный BSL-стек |
| Состояния | Цвет строки, подтверждённый результат, текст ошибки в hover, состояние подключения/запроса | Несовместимый или неполный ответ остаётся неизвестным; ограничения текстового upstream-формата сохраняются |
| Запись | Start/Stop, прямая вставка у каретки, один Undo, повторная запись без обязательной промежуточной вкладки | После внешнего Stop текст остаётся в Vanessa, отдельного безопасного чтения нет |
| Переменные и диагностика | Авточтение переменных, строковое изменение, локальное удаление; журналы, скриншоты, локальный ZIP | Типы и корректное глобальное удаление недоступны в проверенном API |
| Form Explorer | Дерево групп/колонок, фильтры и поиск, детали, выбор окна, общий кеш с IntelliSense и обогащение статическими метаданными | Самопроизвольная смена структуры в той же форме требует Refresh |
| Vanessa steps | Автоматический перенос фокуса на выбранный элемент, debounce 350 мс, очередь последнего выбора, устаревшие ответы не публикуются | Группы/скрытые/неоднозначные элементы не активируются. Это нативные подсказки активного элемента, не отдельная штатная команда проверок текущего элемента |
| Кеш нативных шагов | До 64 элементов одной формы/сеанса/языка, только память; при возврате текст показывается сразу, а актуальность подтверждается в фоне по свежим данным элемента и сообщённому Gherkin-состоянию. Сворачивание блока не вызывает запросов | Предпросмотр из кеша не считается подтверждением свежести. Отсутствие/неоднозначность состояния запрещает reuse анализа; это не дешёвая и не полная ревизия всех UI-данных |
| Вывод шагов | Readonly-текстовое поле со свободным выделением нужных строк; Insert full form checks в Current form | Полные проверки используют прежний нижний Output и явную вставку; обычное выделение текста ничего не вставляет |
| Остальные инструменты формы | Типизированное меню **MCP form tools** для 13 проверенных имён инструментов: поиск, действия с элементами, окнами/командным интерфейсом, запись, выгрузка табличного документа, атрибуты объекта и данные БД | Наличие универсального меню не означает готовый специализированный интерфейс каждой операции. Действия с данными вызываются явно |

## Можно сделать в KOT с существующим API

- Завершить удобный интерфейс **база → пользователи → профили клиентов** в обоих менеджерах баз: выбор, массовое добавление/подключение, сверка текущих профилей и состояний. Сохранённые наборы и MCP-операции уже есть; полноценный интерфейс и согласование конфликтов ещё не реализованы. Недоступные поля порта должны оставаться явно неприменёнными.
- Заменить универсальные формы ввода отдельных инструментов специализированными действиями: поиск/переход к элементу, ввод/выбор, операции с окнами и командным интерфейсом, экспорт табличного документа. Для этого уже есть MCP API; менять бизнес-данные автоматически при выборе элемента не требуется.
- Добавить более удобный просмотр атрибутов объекта и выбранных строк таблицы, не выдавая их за полную UI-таблицу. Типизированный вызов соответствующих инструментов уже доступен через меню.
- Расширить живую матрицу приёмки: разные виды полей/таблиц, большая форма, смена окна во время анализа, отдельный минимальный пример для точек внутри экспортных сценариев. Тесты транспорта и локального webview не заменяют эти проверки.

## Что требует изменения или подтверждения со стороны Vanessa

| Потребность | Ограничение `.45` | Текущий обход / issue |
|---|---|---|
| Быстро получить шаги одного элемента | `full` обходит форму целиком; `max_depth` сокращает вывод, не работу | Автоматическая очередь и кеш; [02](../issues/2026-10-21-vanessa-mcp/02-element-steps.md) |
| Штатная проверка только текущего элемента | UI-команда есть, в MCP `get_form_analysis` не выставляет её флаг | Не подменяется подсказками или проверкой всей формы; [02](../issues/2026-10-21-vanessa-mcp/02-element-steps.md) |
| Фактически прервать анализ и немедленно начать следующий | Отмена devkit фиксирует отметку; кооперативная проверка внутри анализа `.45` не подтверждена | Логическая отмена, серверные операции последовательно. Прерывание HTTP не считается остановкой BSL |
| Кеш без затрат на проверку и без риска пропущенных изменений | Нет дешёвой полной ревизии формы/значений | Проверяется только сообщённое Gherkin-состояние и детали выбранного элемента |
| Надёжно следить за текущим фокусом клиента | Нет переносимого отдельного ID активного элемента | Фокус на выбранный элемент задаётся явно; его независимая смена пользователем во время запроса не полностью наблюдаема; [04](../issues/2026-10-21-vanessa-mcp/04-active-element-identity.md) |
| Язык штатных проверок формы | MCP-генератор не применяет тот же перевод, что UI | Однозначный парный каталог с сохранением непереведённых шагов; [01](../issues/2026-10-21-vanessa-mcp/01-form-checks-language.md) |
| Автовставка после внешнего Stop записи | Нет read-only чтения буфера, повторный Stop может очистить текст; флаг записи до выполнения feature может отсутствовать | Безопасный явный Stop в KOT, отсутствие подтверждения не маскируется; [05](../issues/2026-10-21-vanessa-mcp/05-recording-state-before-run.md), [06](../issues/2026-10-21-vanessa-mcp/06-recording-result-read.md) |
| F11 со скоростью нативного шага уже загруженной feature | Upstream-вызов повторно загружает feature/библиотеки | KOT избегает своих лишних загрузок; нужен отдельный upstream-путь; [07](../issues/2026-10-21-vanessa-mcp/07-step-without-reload.md) |
| Все строки UI-таблицы и замена locator | DB-данные и selected rows не равны всей текущей UI-таблице; эквивалент locator не подтверждён | Snapshot-мост сохраняется; [10](../issues/2026-10-21-vanessa-mcp/10-ui-table-snapshot.md) |
| Полностью структурированные статусы/результаты и глубинные точки | API возвращает текст без стабильной полной модели; точка внутри экспортного вызова требует отдельного воспроизведения | Строгая проверка текущего формата; [11](../issues/2026-10-21-vanessa-mcp/11-structured-state-results.md), [12](../issues/2026-10-21-vanessa-mcp/12-exported-breakpoints.md) |

Русские [черновики issue](../issues/2026-10-21-vanessa-mcp/README.md) предназначены для ручной публикации пользователем. Ничего не отправлено разработчикам автоматически.
