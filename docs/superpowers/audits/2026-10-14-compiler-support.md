# Аудит покрытия компилятора СППР — 2026-10-14

Дополнение 2026-10-15: выполнено [сравнение текущей обработки с предоставленной СППР 2.1.1.31](2026-10-15-compiler-version-comparison.md). У BDD отсутствуют два исправления компиляции; адаптации Drive требуют сохранения при переносе изменений.

Проверено по рабочему дереву KOTfor1C и предоставленным исходникам обработки. Таблицы фиксируют состояние при обнаружении разрывов. Внешний корпус не изменялся. EPF в 1С в рамках этого аудита не запускался: выводы о поведении обработки основаны на конкретных ветках BSL. Полный gate рабочего дерева выполняет основной агент.

По итогам аудита добавлены предупреждения совместимости `kotTestToolkit.compilerFormat` для открытых файлов четырёх compiler kinds: непрочитываемые scalars/flow values, отличающиеся от точного `|` блоки, отступы вне кратности четырём, структурные/inline комментарии и расширение `.yml`. Никаких автоматических преобразований исходников нет; multiline payload, пустые заголовки, sidecars и общие YAML-настройки исключены из этой проверки. Проверка формата и публикация предупреждений прошли targeted red→green regression (23 теста), `tsc --noEmit` и targeted ESLint; общий gate принадлежит основному агенту. Остальные таблицы следует читать как audit findings до реализации последующих исправлений.

Следующим безопасным исправлением Properties/model добавлены `НеобратимоМеняетДанные` и `Ответственный` в предложенные поля сценария, `Выключена` — только в поля настройки сценария. Новые флаги предлагают пусто/Да/Нет, отсутствующее значение остаётся пустым; открытие формы и выбор пустого отсутствующего поля не записывают default. Предложены четыре native parameter types, а уже существующие `Булево`/`Массив` сохраняются в модели, локальном dropdown и YAML. В session добавлено `variantLimitWarning: { count, limit: 100 } | null` для текущего scenario preview, включая значения выбранной настройки. Rendering/localization предупреждения выполняет основной агент; сборка и process route не переписываются.

У supplied BSL есть дополнительная граница: `Подпроцессы` обращается к `ПроцессUID`, тогда как reader заполняет `ВложенныйПроцессUID`. KOT уже адаптирует вложенный ProcessFilter в явный ProcessSettingsFilter до preflight. При неадаптированном неоднозначном definition filter проверка предупреждает и не объявляет неподтверждённый лимит корневого процесса ошибкой. Это не исправление самой обработки.

Ручное имя параметра результата предыдущего шага остаётся доступным — compiler выпускает ссылку на переменную Vanessa и не предоставляет внешний каталог произвольных runtime outputs. Восемь полей ПараметрыШага поддерживаются; дополнительная проверка существования динамической переменной в живом сеансе относится к будущему управлению Vanessa. Внутренние СППР hooks, Git retrieval, HTML/model helpers и новые test engines не становятся внешним YAML API от наличия экспортной BSL-функции.

Объём подтверждения: unit/native-host tests и статическая сверка с предоставленным BSL. Живое исполнение EPF/1С здесь не выполнялось.
