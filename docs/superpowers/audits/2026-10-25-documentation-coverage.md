## Дефект подсказок

Подтверждены и покрыты регрессиями:

- Автоматический показ требовал Scenario-заголовок и исключал native SPPR-фрагмент.
- Граница `\b` после русского ключевого слова отсекала автоматический показ.
- Полностью выделенный аргумент из шаблона использовался как поисковый запрос и скрывал подходящие элементы формы.

Автоматический показ использует общий разбор вставки Gherkin, подтверждает соседние метаданные для native-фрагмента и не срабатывает внутри docstring. Выделение всего содержимого аргумента трактуется как замена, а частичное выделение и чужой редактор сохраняют фильтрацию.

Проверка: `npm run check` — 2581 тест, 2579 успешно, 2 пропущены, 0 ошибок. Выполнена сборка и живая проверка Windows после Reload Window: оба формата предлагают реальные имена кнопок формы Information reference. Отдельно проверена замена целиком выделенного `ButtonName`: список содержит реальные элементы формы. Проверки документации и учебного проекта также прошли. Полная runtime-матрица этим не заявляется.
