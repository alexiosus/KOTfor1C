# Макет первого запуска и страницы настроек

Откройте [index.html](index.html) в браузере. Макет работает без сервера и внешних библиотек; он не вызывает VS Code, не сканирует файлы и не меняет базы или реальные настройки.

Что можно проверить:

1. Пройти четыре маршрута первого запуска. У нового проекта переключить Vanessa / СППР, выбрать «Пока только редактор» или раскрыть подключение 1С без дублирующей галочки, посмотреть обзор панелей и итоговый план. Сравнить первые примеры Vanessa и СППР (единый YAML и feature + meta).
2. В режиме настроек выбрать один из восьми разделов, найти параметр, выбрать область, изменить значение, сбросить его, применить или отменить изменения учебного черновика.
3. Открыть «Обзор…» у пути: расположение внутри проекта сохраняется относительным путём, внешнее — полным. Пикер показывает **учебные** расположения. Настоящий системный диалог будет подключён в VS Code, браузер не читает папки компьютера.
4. У настройки открыть popup со значком `i`: наведение, фокус клавиатурой и закрепление кликом. Источник и сброс появляются при наведении или фокусе на поле. «Отключённые проверки» выбираются из списка с флажками; значения соответствуют enum manifest.
5. Вернуться в начало по иконке KOT или кнопке «В начало». Поля и черновик сохраняются при переходе внутри макета; перезагрузка браузера сбрасывает учебное состояние.
6. Уменьшить ширину окна и пройти формы с клавиатуры.

[Полный проект](../../superpowers/specs/2026-10-24-first-run-and-settings-design.md) описывает сохранение, миграцию, ограничения и приёмку. [settings-map.json](settings-map.json) покрывает все **83** текущие настройки manifest; их имена и значения по умолчанию сохраняются. `settings-data.js` — сгенерированный снимок этой карты для автономного HTML, а не новое хранилище настроек расширения.

Проверка `npm run verify:demo` также сверяет полноту карты и совпадение снимка. При добавлении или изменении настроек обновляйте карту и снимок вместе. Результаты обнаружения в мастере — намеренно подписанные учебные примеры.

Проверено в браузере: все четыре маршрута до итогового экрана; отсутствие требования компилятора в маршруте Vanessa; план переноса для раннего KOT; поиск по существующему ключу; сохранение черновика при смене области; применение и сброс значения; наследование кнопок от общего переключателя. В окне шириной 661 px горизонтального переполнения формы нет. По проверке проекта уточнены границы подготовки служебной базы и сохранения во внешних менеджерах. Это проверка макета, а не интеграционный тест готового мастера в VS Code.

После замечаний к макету уточнены выгрузка компилятора СППР в `.epf`, автоопределение версии библиотеки шагов Vanessa и смысл трёх настроек совместимости. Эти настройки скрыты под отдельным раскрытием; повторная подпись внизу навигации убрана. Иконка взята из Activity Bar KOT и окрашивается цветом текста темы через маску, поэтому видна на тёмном фоне.

Повторно проверено после правок: относительный и внешний путь Vanessa, сохранение и применение списка проверок, появление источника при фокусе поля, popup с клавиатуры и закрытие Escape, поиск настроек совместимости и три варианта первого примера. В открытом окне 805 px горизонтального переполнения нет; иконка KOT видна на тёмном фоне. Автоматическая проверка дополнительно сверяет варианты массива проверок с `items.enum` manifest.
