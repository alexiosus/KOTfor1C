# Самостоятельные feature Vanessa

Самостоятельная feature — обычный файл Gherkin, который Vanessa выполняет без компиляции СППР. Он появляется в отдельной секции Менеджера тестов и в Библиотеке.

## Создать тест

Нажмите **+** секции самостоятельных feature либо выберите создание feature в меню KOT. Укажите имя и язык. Возможен собственный шаблон из настроек расширения.

```gherkin
#language: en
Feature: Remember a customer

Scenario: Save a value
    And I save "Demo customer" in "Customer" variable
```

Откройте свойства: доступны заголовок, описание, теги, группа, список сценариев и JSON запуска. Кнопка **+** у сценариев добавляет Scenario или Scenario Outline. Отдельные действия добавляют Background, Variables, импорты и примеры.

## Запустить

1. Выберите существующий JSON запуска либо создайте его из активного профиля.
2. Проверьте подключение Vanessa и нужный клиент тестирования.
3. Нажмите **Run** в свойствах, редакторе или Менеджере тестов.

Для повторного использования подключённого менеджера учитываются его текущие настройки. Vanessa `.45` не умеет принять весь новый JSON через MCP в уже работающий сеанс; KOT предупреждает о различиях.

Имя feature можно менять отдельно от имени файла. Группы и размещение общие для Менеджера тестов и Библиотеки; избранное остаётся личным.

## Что не считается самостоятельным тестом

Экспортная библиотека содержит повторно используемые сценарии. Парный `scen.feature` рядом с `meta.yaml` — исходник СППР. Выходная feature компилятора — результат сборки. KOT различает эти роли, чтобы не показывать один тест несколько раз.
