# Подключение ИИ

Прямой LLM-клиент и его настройки API удалены из KOT 3.1.0. Эта страница сохранена для прежних ссылок; примеры настройки LM Studio, Ollama, OpenAI, Gemini и Azure к текущей версии KOT не применяются.

Используйте **Подключить ИИ** в настройках KOT. Для Codex и Claude Code мастер создаёт проектное MCP-подключение и устанавливает навык. Вариант **Другой MCP-клиент** проверяет локальный маршрут и открывает памятку с конфигурацией для копирования и первым запросом без обязательного скилла. Авторизация и выбор модели выполняются в выбранном клиенте.

[Пошаговое подключение агента](ai-agent.md) · [Что стало с прежними функциями и отчётами](ai-description.md)

Старые записи настроек API в пользовательском или проектном JSON больше не используются. KOT не удаляет их автоматически.
