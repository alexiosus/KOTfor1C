# Выбор платформы 1С

KOT хранит каталог платформ, чтобы компиляция, Vanessa и информационные базы использовали нужную установленную версию.

Откройте **Управление платформами 1С** из меню KOT или соответствующий раздел настроек. На Windows доступно обнаружение установленных версий; запись можно добавить вручную и указать путь к клиенту.

## Настроить

1. Проверьте найденные версии и путь к исполняемому файлу.
2. Задайте платформу по умолчанию.
3. При необходимости назначьте предпочтительную платформу отдельной базе.
4. Решите, нужно ли спрашивать выбор при каждом запуске.

Имя записи предназначено для человека. Решающее значение имеет фактический путь и доступность нужного режима запуска. Предприятие и Конфигуратор — разные действия, даже если относятся к одной установленной платформе.

Если установленная версия изменилась или каталог удалён, обновите запись перед компиляцией. Каталог платформ не устанавливает 1С и не заменяет системную установку.

Локальное выполнение в KOT рассчитано на Windows. Наличие настроек платформ в окне macOS/Linux само по себе не включает поддержку локального запуска.
