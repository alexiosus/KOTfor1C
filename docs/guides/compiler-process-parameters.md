# Параметры процессов и настроек запуска

Процесс позволяет один раз задать общие данные для цепочки сценариев, а затем уточнять их у отдельного шага. Настройка запуска добавляет конкретный вариант такого теста.

## Разделить уровни

| Уровень | Для чего нужен |
|---|---|
| Параметр сценария | Значение по умолчанию повторно используемой проверки |
| Параметр процесса | Общие данные процесса и его вложенных шагов |
| Параметр отдельного шага процесса | Уточнение для одного вызова |
| Параметр настройки запуска | Данные конкретного варианта самостоятельного теста |
| Переменная Vanessa | Значение, полученное уже во время выполнения |

Например, процесс «Проверить заявку» использует одного **Customer** во всех шагах. Отдельная настройка запуска задаёт другого покупателя, а один шаг может получить своё уточнение. Изменение этого варианта не требует менять defaults вложенного сценария.

## Настроить в свойствах

1. Откройте процесс и добавьте общие параметры.
2. В списке шагов выберите сценарий или подпроцесс.
3. Проверьте ожидаемые параметры и передайте нужные значения.
4. У главного процесса откройте настройки запуска и задайте значения конкретного прогона.
5. Скомпилируйте процесс и проверьте итоговую feature.

При вставке вызовов KOT использует доступные объявления. Сложные случаи — таблицы, исходящие значения, сочетания вариантов и несколько уровней процессов — оценивайте по результату компиляции, а не по виду строки в редакторе.

## Теги и варианты

Теги сценария/процесса и фильтры активного профиля участвуют в отборе при сборке. Галочка Менеджера тестов задаёт желаемый набор, но не отменяет выключение в настройке запуска или фильтр компилятора.

Имена исходных блоков — `ПараметрыСценария`, `ПараметрыПроцесса`, параметры шага и настройки — остаются по формату СППР. Общий JSON запуска Vanessa относится уже к следующему этапу.
