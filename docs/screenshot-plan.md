## Что можно улучшить без новых разделов

- В следующей записи действий показать клиент 1С рядом с редактором и оставить результат на экране на 2–3 секунды. Текущий короткий финал дополнен неподвижным кадром.
- При необходимости дополнить меню создания следующим экраном с именем и форматом, а список клиентов — раскрытым редактором подключения.
- Для перехода по ошибке компиляции добавить короткое видео клика по `scen.feature:8`. Имеющийся снимок уже объясняет сам отчёт.

## Использование в учебных уроках

В уроках 3–5 добавлены ссылки на иллюстрированные руководства и видео. Дублировать большие изображения в каждом уроке не требуется: читатель может открыть нужный пример из соответствующего упражнения.

Обзоры полной Библиотеки, Исследователя формы, информационных баз и параметров сборки находятся в [карте интерфейса](interface.md#полные-панели-инструментов). Контекстное меню редактора показано в [отдельной карте действий](context-menus.md). Для подписей поверх новых кадров достаточно 3–5 областей; последовательность работы лучше оставить в тексте.

Оставшиеся места вставки:

```sh
rg -n 'screenshot-slot:' docs/guides
```
