# Локальные результаты сборки

Пакеты расширения хранятся в `vsix/`. Содержимое этого каталога исключено из Git и поставки расширения; README описывает назначение папки.

При упаковке задавайте выходной файл в этом каталоге, например:

```sh
vsce package --out artifacts/vsix/kot-test-toolkit.vsix
```

Сборка JavaScript по-прежнему создаётся в `out/`. Правила подготовки поставки — в [руководстве разработчика](../docs/DEVELOPMENT.md#подготовка-поставки).
