# Пользовательский шаг

[WorkshopSteps.bsl](WorkshopSteps.bsl) показывает исходник пользовательского шага Vanessa. Он нужен для чтения, поиска и навигации в KOT.

Для выполнения разработчик 1С должен включить этот модуль в обработку с поддержкой регистрации шагов Vanessa и собрать `.epf`. Один BSL-файл не является готовой библиотекой выполнения. После этого укажите каталог обработки в `Libraries` / «КаталогиБиблиотек». Основные учебные сценарии этот шаг не вызывают.
