# Пользовательский шаг

[WorkshopSteps.bsl](WorkshopSteps.bsl) показывает исходник пользовательского шага Vanessa. Он нужен для чтения, поиска и навигации в KOT.

Один BSL-файл не является готовой библиотекой выполнения. Основные учебные сценарии этот шаг не вызывают. В Библиотеке KOT он имеет состояние **Только исходник**; IntelliSense, копирование и вставка станут доступны после сборки. Если добавить его вызов вручную без подключения EPF, Vanessa сообщит **«Синтаксическая ошибка: шаг не найден»**.

## Подготовить выполнение

Для этого упражнения нужны платформа 1С и установленная Vanessa Automation с шаблоном `lib/TemplateEpfUF`.

1. В полной Библиотеке найдите и выберите `я показываю учебное сообщение`. В подробностях шага, в блоке **Библиотека EPF**, нажмите **Создать EPF-библиотеку…** и задайте имя `WorkshopSteps`. Это действие также доступно в контекстном меню шага полной и панельной Библиотеки.
2. KOT скопирует учебный модуль в проект обработки по шаблону Vanessa и запустит сборку через Конфигуратор. Исходный файл останется на месте. После успешной сборки новое определение шага будет доступно для вставки; для английского учебного проекта используйте `And я показываю учебное сообщение`.
3. Дальнейшие изменения вносите в открытый модуль внутри `step_definitions-src/WorkshopSteps/`. Первоначальный BSL сохраняется, но не создаёт дубликат шага в Библиотеке. После правок состояние станет **Нужна пересборка**. Повторно выполните **Собрать EPF** у шага либо выберите библиотеку через общую кнопку **Библиотеки EPF**.
4. Проверьте, что каталог с полученной EPF входит в **КаталогиБиблиотек** запущенной Vanessa. `Libraries` в профиле СППР задаёт путь для компиляции и поиска в KOT; у уже работающего менеджера Vanessa могут быть свои параметры библиотек.
5. Обновите библиотеку шагов в Vanessa либо перезапустите учебный сеанс с нужными параметрами. Убедитесь, что шаг появился в списке известных шагов Vanessa, затем выполняйте его.

При языке feature `en` используйте префикс `And`, при `ru` — `И`. Текст самого шага может быть русским в обоих случаях. Проверка языка и наличие EPF — отдельные условия: исправление одного не устраняет другое.

В учебном модуле объявлены экспортные переменные `Контекст` и `КонтекстСохраняемый`: Vanessa заполняет их перед выполнением шага. Сохраняйте эти объявления при редактировании библиотеки. Без них ошибка может возникнуть ещё до вызова процедуры шага; Vanessa 1.2.043.45 при этом способна вернуть сообщение «Несоответствие типов (параметр номер '1')» без красной строки в своём редакторе.

## Получить исходники готовой EPF

Нажмите **Библиотеки EPF → Выгрузить исходники…**, выберите обработку и имя нового каталога исходников. Если EPF находится вне настроенных библиотек проекта, KOT импортирует её копию в выбранную библиотеку, сохраняя исходную обработку. Существующие EPF и каталоги исходников не перезаписываются. Действие **Выгрузить исходники…** также доступно у шага с готовой EPF.
