# Учебная мастерская KOT for 1C

Это проект для знакомства с KOT. Здесь мы готовим небольшую учебную заявку: запоминаем покупателя, передаём данные между сценариями и получаем результат. Первые упражнения ничего не записывают в прикладную базу.

## Начните здесь

1. Установите **KOT for 1C** в VS Code.
2. Откройте **эту папку отдельно** через **Файл → Открыть папку**. Или откройте [KOT-workshop.code-workspace](KOT-workshop.code-workspace) командой **Файл → Открыть рабочую область из файла**. Не открывайте весь репозиторий расширения для выполнения уроков: тогда в списки попадут другие примеры.
3. Откройте [первый самостоятельный сценарий](tests/vanessa/01-first-steps.feature). Найдите слева значок KOT, а справа — **Свойства теста**.
4. Пройдите [знакомство с интерфейсом](guide/01-interface.md), затем [упражнения в редакторе](guide/02-editor.md).

Читать, редактировать сценарии и знакомиться с панелями можно **без установленной 1С**. Каталог встроенных шагов Vanessa загружается при наличии сети; после загрузки используется кэш. Для запуска шагов понадобится 1С и Vanessa, а для компиляции СППР — ещё обработка компилятора.

## Где лежат файлы

- **`tests/sppr`** — сценарии и процессы СППР. У главных объектов есть папка **`test`** с настройками запуска.
- **`tests/vanessa`** — самостоятельные feature-файлы, которым компиляция СППР не нужна.
- **`libraries`** — экспортный сценарий Vanessa и учебный исходник пользовательского шага.
- **`config`** — примеры параметров компиляции, параметров Vanessa, глобальных переменных и каталога эталонных баз.
- **`.kot`** — общие группы, справочники и авторские серии. Файлы **`*.kot.yml`** рядом со сценариями хранят их описание, группу и порядок.
- **`guide`** — это руководство. **`exercises`** содержит строки для безопасных упражнений с диагностикой.

Все пути в проекте относительные. Реальные пути к платформе 1С, Vanessa и компилятору задайте на своём компьютере. Готовые `.epf`, `.dt`, пароли и рабочие базы в демо не входят. Файлы `config` не применяются сами: импорт описан в руководстве.

Названия объектов объяснены в [словаре KOT, СППР и Vanessa](../../documentation/terminology.md). Предыдущий небольшой набор YAML-примеров сохранён в [tests](../../tests/README.md).
