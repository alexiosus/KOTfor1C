# Учебные параметры

При первом открытии мастерской KOT использует собственный профиль **KOT Workshop** из [начального набора проекта](../.kot/parameter-profiles.json): учебные пути, библиотека `libraries`, язык генератора `en` и глобальные переменные уже заполнены. Профили других проектов не меняются. Этот профиль подходит для знакомства с исходниками; для выполнения нужно подключить установленную 1С и Vanessa.

Файлы ниже позволяют отдельно изучить настройки и повторить импорт. Вручную загружать их для первого знакомства теперь не требуется. После изменения локального профиля он имеет приоритет над начальным набором; импорт позволяет вернуть значения нужной вкладки.

| Файл | Куда загрузить | Что проверить |
|---|---|---|
| [sppr-build.json](sppr-build.json) | Параметры компиляции и запуска → СППР → импорт JSON | Корни исходников, выходная папка, каталог библиотек. `CreateJson = false` позволяет начать с компиляции без подготовки полного запуска. |
| [vanessa-additional.json](vanessa-additional.json) | Вкладка параметров Vanessa → импорт JSON | Язык генерации `en`, каталог `libraries`. Для уже работающего сеанса проверьте, какие параметры реально используются. |
| [global-vars.json](global-vars.json) | Вкладка глобальных переменных → импорт JSON | Только учебные имена и значения. Они не являются параметрами `[Имя]` компилятора. |
| [bases.yaml](bases.yaml) | Каталог эталонных баз; его путь указан в `ModelDBSettings` | Путь к своей выгрузке DT и профиль пользователя, если требуется восстановление. Пустые логин и пароль — пример, а не обещание доступа к любой базе. |

Файлы `.json` рядом с самостоятельными feature — параметры запуска Vanessa для этих файлов. Реальные пути к платформе, компилятору и Vanessa задаются в настройках вашего компьютера. KOT подставляет текущий выбранный feature при запуске; после переноса проекта проверьте пути библиотек.
