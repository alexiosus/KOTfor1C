# 1. Осмотритесь в KOT

Откройте [01-first-steps.feature](../tests/vanessa/01-first-steps.feature). В нём две строки `Scenario:` — два сценария одной функциональности. Текст после `And` — действия, которые выполнит Vanessa.

| Где | Что вы там делаете |
|---|---|
| **KOT → Менеджер тестов** слева | Выбираете главные сценарии и процессы СППР для компиляции, запускаете готовые тесты, видите результаты. Самостоятельные feature-файлы находятся в отдельной секции. |
| **Библиотека** в боковой панели | Ищете встроенные и пользовательские шаги, вложенные и экспортные сценарии. В заголовке можно открыть большую версию библиотеки. |
| **Информационные базы** в KOT | Открываете базу и управляете её клиентами тестирования. Стрелка раскрывает список клиентов. Большая версия показывает подробности базы. |
| **Свойства теста** справа | Редактируете имя, параметры, группу и вложения; для feature видите сценарии и параметры запуска Vanessa. Вверху находятся сохранение, запуск, избранное и закрепление. |
| **Переменные сеанса** справа | После подключения Vanessa видите значения переменных выполняемого сценария. До подключения список может быть пустым. |
| Нижняя строка VS Code | Состояние соединения с Vanessa. По нему можно понять, подключён ли менеджер тестирования. |

Названия могут быть английскими, если так настроен язык VS Code: **Test Manager**, **Library**, **Infobases**, **Test properties**, **Runtime variables**. Это те же панели.

Попробуйте открыть [главный сценарий СППР](../tests/sppr/01-first-scenario/scen.yaml), затем [раздельный исходник СППР](../tests/sppr/02-feature-and-metadata/scen.feature). Свойства должны переключиться на выбранный объект. Закрепление в шапке оставляет свойства текущего объекта на экране.

Если сценарии не появились, откройте **Параметры компиляции и запуска** из меню Менеджера тестов. В разделе СППР установите `ScenarioFolder = tests` и `ProcessFolder = tests`. Это корень учебных исходников. В [следующем уроке](02-editor.md) поясняется, зачем добавлять каталог библиотек.

Не путайте **Менеджер тестов KOT** с **менеджером тестирования Vanessa**. Первый — панель VS Code, второй — отдельный сеанс 1С, который выполняет шаги.
