# 4. Запустите шаги в Vanessa

Для выполнения нужна установленная платформа 1С на Windows и Vanessa Automation. Возможности пошагового управления требуют совместимого MCP-сеанса Vanessa. KOT умеет подготовить служебную базу и подключиться к найденному локальному сеансу; необходимые компоненты и параметры описаны в [руководстве управления Vanessa](../../../documentation/blocks/vanessa-control.md).

## Первый запуск без прикладной формы

1. В настройках укажите путь к `vanessa-automation.epf`, убедитесь, что KOT нашёл платформу 1С, и нажмите подключение Vanessa в KOT. Если служебный сеанс ещё не запущен, KOT подготовит его при корректной настройке окружения.
2. В **Параметрах компиляции и запуска** на вкладке Vanessa загрузите [vanessa-additional.json](../config/vanessa-additional.json). Здесь указан язык генерируемых шагов `en` и учебная библиотека. На вкладке глобальных переменных можно загрузить [global-vars.json](../config/global-vars.json).
3. Откройте [01-first-steps.feature](../tests/vanessa/01-first-steps.feature) и нажмите запуск в свойствах. Рядом есть [JSON параметров Vanessa](../tests/vanessa/01-first-steps.json). Проверьте путь учебной библиотеки в текущем окружении.
4. Эти сценарии только сохраняют переменные в сеансе Vanessa. Подключать прикладной клиент тестирования для них не требуется.
5. В панели **Переменные сеанса** найдите `WorkshopCustomer` и `WorkshopMessage`. После выполнения второй сценарий оставит сообщение «Заявка проверена».

Если уже подключён сеанс с другими параметрами, KOT предложит использовать его текущие параметры или подготовить отдельный менеджер. Для первого знакомства удобнее собственный учебный сеанс. Самостоятельная feature запускается без компиляции СППР.

## Выполняйте по одному шагу

Поставьте курсор на строку `And` и нажмите **F11**. Посмотрите цвет строки и новое значение переменной. На следующей строке поставьте точку останова в левом поле редактора. Попробуйте запуск с текущего шага, остановку и продолжение. Наведение на неуспешный шаг показывает сообщение об ошибке, если Vanessa или журнал вернули его.

Выделите две строки `And` и выполните команду запуска выделенных шагов из подменю KOT. Заголовки `Feature`, `Scenario` и таблица `Examples` сами по себе не являются шагами для запуска. Для СППР KOT может подготовить пробное выполнение прямо из исходного YAML или `scen.feature`, не требуя предварительной полной компиляции; это проверка выбранных шагов, а не замена компиляции всего процесса.

Панель переменных позволяет менять строковые значения и выполнять поддерживаемые операции удаления. Возможности ограничены API вашей Vanessa. Глобальные переменные и локальный контекст — разные разделы; пустой список без активного выполнения не означает потерю настроек.

## Запишите реальные действия

Для этого упражнения уже нужен клиент тестирования из [следующего урока](05-infobases.md).

1. Создайте копию первого feature и поставьте каретку внутрь сценария, после существующих шагов.
2. Включите запись из редактора KOT.
3. В клиенте тестирования откройте знакомую форму и выполните несколько простых действий.
4. Остановите запись в KOT или Vanessa. Полученный текст вставляется в выбранный сценарий. Проверьте действия и параметры перед сохранением.

Язык создаваемого сценария задаётся в настройках редактора, а язык записи и проверок — параметром Vanessa **ЯзыкГенератораGherkin**. В демо оба имеют значение `en`; эти настройки решают разные задачи.

## Результаты и диагностика

При полном выполнении смотрите цвета строк и результат в Менеджере тестов. Для управляемого сеанса KOT использует доступное состояние MCP и журнал его запуска; быстрые промежуточные шаги зависят от того, какие данные возвращает версия Vanessa и настроен ли журнал. Журнал, отчёты и созданные feature можно открыть из действий теста. В меню Vanessa также доступны сбор диагностики, поиск шагов текущего сеанса и проверка синтаксиса через Vanessa.

Учебные исходники проверяются средствами KOT; комплект не содержит заранее записанного «успешного прогона» вашей базы. Для реального выполнения нужна подготовка окружения выше.
