A · Файлы прямо под сценарием

Строка сценария раскрывается в центральном списке. Поведение совпадает с компактной панелью; файлы видны рядом с названием сценария.

B · Файлы в панели сведений

Центральный список остаётся плоским, а дерево Files показывается справа только для выбранного сценария. Больше места, но структура отличается от компактной панели.

Рекомендация: вариант A — единая модель взаимодействия в обеих версиях библиотеки.
