# Источники данных Form Explorer

Пользовательский интерфейс объединяет MCP-источник, прежний мост TestManager/TestClient и статическое обогащение. Их данные нельзя считать одинаковыми по полноте или свежести.

## MCP

При подходящем сеансе KOT получает дерево/детали через инструменты Vanessa, проверяет идентичность клиента и окна и публикует только актуальный ответ. Нативные подсказки активного элемента и проверки всей формы — отдельные операции. Ограничения перечислены в [контракте MCP](execution-and-mcp.md).

## Прежний мост

Bridge работает через отдельную связку менеджера и клиента тестирования и передаёт snapshot файлами. Состояние и команды обновления находятся в каталоге generated artifacts; основной путь snapshot задаётся настройкой.

| Файл | Назначение |
|---|---|
| `form-snapshot.json` | Последний снимок формы |
| `adapter-mode.txt` | Фактический режим manual/auto |
| `adapter-mode-request.txt` | Запрос смены режима |
| `adapter-request-context.json` | Контекст запроса обновления/таблицы/locator/режима |
| `bridge/bridge-config.json` | Конфигурация bridge-сеанса |
| `bridge/bridge-status.txt` | Состояние моста |
| `forms-index.json` | Статический индекс форм |

Режим manual обновляется по явному действию. Auto периодически читает данные в пределах настроек моста. Наличие файлового snapshot само по себе не подтверждает, что соответствующий клиент ещё активен.

Формат снимка содержит `schemaVersion`, время, `source`, сведения `form` и коллекции элементов, таблиц, атрибутов и команд. Не все источники возвращают все поля. Актуальные TypeScript-типы и нормализация находятся в [formExplorerTypes.ts](../../src/formExplorerTypes.ts); мост — в [KOTFormExplorerBridge.bsl](../../res/formExplorer/bridge/KOTFormExplorerBridge.bsl).

## Статические сведения

`configurationSourceDirectory` указывает файловую выгрузку 1С. Из `Form.xml` и доступных metadata извлекаются источники, tooltip и пути данных для обогащения UI и IntelliSense. Статический источник не должен подменять живое значение поля.

Старая `.cfe`-генерация оставлена для совместимости; она не является обязательным первым шагом подключения MCP. Не используйте инструкции старого adapter-пути как универсальное требование для новой сессии.
