# Выполнение и MCP Vanessa

Матрица описывает реализованную интеграцию KOT 3.0.0 и проверенный контракт Vanessa Automation **1.2.043.45**. Это не заявление о произвольной версии EPF или текущем upstream develop.

## Участники

```text
VS Code / KOT
    ↕ MCP
Менеджер тестирования 1С с Vanessa + client MCP devkit
    ↕ штатное управление тестированием 1С
Клиент тестирования проверяемой информационной базы
```

Devkit предоставляет транспорт/сервер в клиентском сеансе менеджера; инструменты управления объявляет Vanessa. VAExtension относится к возможностям на стороне тестового клиента, а не заменяет транспорт MCP менеджера. Не каждая команда управления менеджером требует одинакового набора клиентских компонентов.

## Подготовка и соединение

Управляемый запуск использует существующую служебную ИБ KOT, проверяет компонентный manifest/подготовку и ожидает handshake и объявления инструментов. Подготовленный DT может содержать devkit; старой служебной базе предусмотрена установка без полного восстановления DT при соблюдении условий запуска.

Attach к работающему менеджеру не переустанавливает его базу. Обнаружение локального endpoint дополняется ручными настройками. Доступность HTTP-адреса без подходящей схемы инструментов не означает готовый сеанс Vanessa.

Безопасный режим компонента и установка нативной части относятся к подготовке 1С. Не следует менять рабочие ИБ только для подключения KOT. Версии и исходники компонентов перечислены в [лицензиях](../../THIRD_PARTY_LICENSES.md).

## Доступное поведение и границы

| Область | Что использует KOT | Ограничение проверенного API |
|---|---|---|
| Выполнение | Run, с шага, F11, выделение, Stop и подтверждённое продолжение | Не произвольная остановка/восстановление BSL-стека |
| YAML до компиляции | Служебная feature для обычного однозначного шага | Не общий интерпретатор СППР |
| Результаты | Состояние, результаты и дополнение фактическим журналом | `get_test_results` без ID относится к последнему сценарию; опрос пропускает быстрые переходы |
| Полный JSON | Запуск/сверка параметров и явное решение о различиях | Нет общей операции загрузить весь JSON в активный менеджер `.45` |
| Запись | Start/Stop и вставка результата у каретки | Нет безопасного отдельного чтения после Stop в самой Vanessa; до первого выполнения статус может отсутствовать |
| Переменные | Чтение, строковое изменение и локальное удаление | Нет полного контракта типов/глобального удаления |
| Нативные шаги элемента | Активация выбранного элемента и анализ активного | Не штатная команда «проверка текущего элемента в виде шагов» |
| Форма | Дерево, значения/детали, окна, кеш, типизированные инструменты | Не полный интерактивный UI каждого MCP-инструмента; данные БД не равны строкам UI-таблицы |
| Профили клиентов | Живые/сохранённые строки, добавление и подключение | Profiles API `.45` не подтверждает применение сохранённого порта |
| Отмена | Отбрасывание устаревшего ответа и отмена доступного клиентского ожидания | Не гарантия прерывания синхронной операции Vanessa |
| Снимки | Выбор клиента/окна и чтение собственного временного PNG | Файловый ответ `.45` рассчитан на локально доступный путь; удалённому сеансу нужен подходящий формат данных |

## Состояние и сопоставление строк

Статусы привязаны к сеансу, feature и актуальному запуску. Снимок, полученный до нового запуска, не должен окрашивать его. Повторяющиеся шаги сопоставляются только при подтверждённом порядке; неопределённый результат не считается успешным.

Новые менеджеры KOT получают постоянный журнал `logs/vanessa-mcp-<порт>.log`. Для существующего менеджера важен **фактический** путь его журнала, а не похожий файл артефакта. Во время Run чтение начинается от текущего конца, чтобы не проигрывать прежний прогон.

Для выбранного элемента формы KOT использует задержку переключения и очередь актуального выбора. Устаревший ответ не публикуется. Кеш ограничен формой/сеансом/языком и не считается доказательством неизменности всех UI-данных. Сворачивание Vanessa steps не запускает новый запрос.

## Диагностика и оставшаяся приёмка

Отчёты и ZIP локальные. Текстовая очистка стандартных секретов не редактирует изображения. Журналы читаются явно и в ограниченном объёме; ошибка раздела не должна скрыть остальные результаты.

Исторические живые наблюдения и проекты upstream issue находятся в [аудите](https://github.com/alexiosus/KOTfor1C/blob/codex/reliability-foundation/docs/superpowers/audits/2026-10-21-vanessa-capabilities.md). Отдельно доступны [черновики upstream issue](https://github.com/alexiosus/KOTfor1C/blob/codex/reliability-foundation/docs/superpowers/issues/2026-10-21-vanessa-mcp/README.md). Эти материалы датированы и не заменяют приёмку выбранной сборки Vanessa. В этой редакции документации не заявляется новая полная Windows/1С-матрица.
