# Сохранённый набор клиентов для отдельного запуска

Для повседневного управления активной MCP-сессией используйте [Информационные базы и клиентов](infobase-manager.md). Отдельный механизм **клиентов ручной отладки Vanessa** сохранён для совместимости с соответствующими маршрутами запуска.

Команда **Настроить клиентов отладки Vanessa** сохраняет локальный набор клиентов для рабочего пространства. Можно выбрать базу из менеджера либо указать строку подключения, пользователя и дополнительные ключи. Имена клиентов должны различаться.

Выбор **Использовать параметры сценария** отключает подстановку этого набора, не удаляя его. Регистрация профиля не означает автоматическое подключение клиента: его могут выполнять шаги или команды Vanessa.

Чувствительные поля хранятся через SecretStorage. Создаваемый для отдельного запуска временный JSON не следует путать с общим файлом параметров проекта. Настройка этого набора не меняет произвольно уже работающий MCP-менеджер.
