## Клиенты ручной отладки Vanessa

Команда **KOT: Настроить клиентов отладки Vanessa** доступна в палитре команд и в меню открытия Vanessa. Она сохраняет один локальный набор из одного или нескольких клиентов для текущего рабочего пространства. При первом Debug настройка открывается автоматически; после сохранения набор используется при следующих запусках.

Для каждого клиента укажите имя профиля, которое используют шаги Vanessa, и базу из менеджера баз, файловую папку или серверную строку `Srvr="server";Ref="infobase";`. Пользователь, пароль и произвольные дополнительные ключи запуска необязательны. Поле **Дополнительные ключи запуска клиента (необязательно)** находится в основном мастере: например, можно указать `/NoSplash /Lru`. В дополнительных настройках доступны тип клиента, компьютер, порт, синоним и повторное редактирование ключей. Имена клиентов должны отличаться; клиенты на одном компьютере используют разные порты.

В JSON для Vanessa `ПутьКИнфобазе` / `PathToInfobase` содержит только расположение базы. Пользователь и пароль передаются как `/N"имя" /P"пароль"` в `ДопПараметры` / `AddItionalParameters` вместе с пользовательскими ключами. Если оба отдельных поля пусты, KOT берёт учётные данные из `Usr` / `Pwd` в сохранённой строке подключения. Непустое отдельное поле пользователя или пароля заменяет встроенные учётные данные. Существующие сохранённые наборы используются без повторного ввода; исправленный формат создаётся при следующем Debug-запуске.

**Сохранить и использовать клиентов отладки** включает набор. **Использовать параметры сценария** отключает его подстановку и сохраняет набор для последующего включения. Отмена закрывает редактор без сохранения; при первой настройке она также отменяет Debug.

Настройка применяется к общему Debug Vanessa, Debug собранного теста и Debug самостоятельного `.feature`. Ручной запуск использует отдельный временный JSON с отключёнными автоматическим выполнением сценариев и закрытием Vanessa; исходный JSON сохраняется. Обычный автоматический Run использует свои параметры запуска.

Пароли, полные строки подключения и дополнительные ключи хранятся в защищённом хранилище VS Code. Они не записываются в настройки проекта. Временный JSON запуска имеет ограниченные права доступа и удаляется после завершения запущенного процесса или ошибки запуска.

Список регистрирует профили клиентов в Vanessa. Подключение конкретного клиента выполняют шаги сценария или команды самой Vanessa.
