# Менеджер тестов

Менеджер тестов находится в боковой панели KOT. Здесь выбирают набор для компиляции, открывают результаты и запускают тесты. Он не является сеансом 1С с Vanessa.

## Какие объекты видны

- **Главные сценарии** СППР — сценарии с настройкой запуска.
- **Процессы** — главные процессы с настройкой запуска.
- **Самостоятельные feature** — тесты Vanessa без компиляции СППР.

Вложенные сценарии и процессы без настроек запуска остаются в Библиотеке. Чтобы сделать их самостоятельными, используйте [Преобразования](scenario-source-formats.md).

## Выбрать набор

Отмечайте нужные строки или группу целиком. Команда **Скомпилировать / Compile** использует выбранный набор и активный профиль; фильтры компилятора и свойства настройки запуска также влияют на результат.

Группы можно создавать, переименовывать и менять их состав. Принадлежность и порядок элементов — общие данные проекта, порядок показа групп и раскрытие — личное состояние. Пустая группа **Без группы / Ungrouped** остаётся доступной для перемещения элементов.

Поиск, фильтры состояния и связи помогают сократить список. Если тест пропал, проверьте фильтр, раскрытие группы и наличие настройки запуска, затем обновите каталог.

## Скомпилировать и запустить

1. Выберите профиль рядом с кнопкой компиляции.
2. Отметьте главные тесты и запустите сборку.
3. При ошибке откройте отчёт компилятора и перейдите к исходной строке.
4. После успеха откройте feature/JSON или нажмите запуск у результата.

Отмена сборки доступна во время операции. Индикатор **Устарел** означает, что изменился исходник, зависимость или форма организации теста. Перед обычным запуском рекомендуется пересобрать такой тест.

Если несколько сценариев объединены компилятором в одну feature, запуск строки выполняет весь общий файл. Это не отдельный прогон только одной строки дерева.

## Подключение Vanessa и дополнительные действия

**Подключить Vanessa** подготавливает управляемый сеанс; при подключении доступны управление и настройки. Текущее состояние видно в нижней строке VS Code. Меню Менеджера тестов открывает параметры, настройки подключения, AI-инструменты и другие действия.
