# Начало работы и настройки KOT

Откройте меню панели KOT → **Настройки расширения**. Оно открывает страницу KOT с разделами настроек; мастер при этом не запускается. Кнопка **Открыть настройки VS Code** ведёт к тем же параметрам в обычном редакторе настроек VS Code.

Чтобы подготовить проект, нажмите **Начать настройку проекта** на странице или выполните команду `KOT: Настроить проект` в палитре. При первом открытии папки KOT также предлагает знакомство. Это предложение можно закрыть или отключить.

## Какой маршрут выбрать

- **Начинаю с нуля** — создаёт небольшой пример в открытой папке. Выберите обычную feature Vanessa или сценарий СППР. Для изучения всех возможностей используйте **Открыть копию учебной мастерской**: KOT скопирует комплект в новую папку `KOT-workshop` и откроет отдельное окно. Существующая папка не заменяется.
- **У меня проект СППР** — найдёт сценарии, процессы и настройки запуска. Поддерживаются единый `scen.yaml` и раздельные `scen.feature` + `meta.yaml`.
- **У меня проект Vanessa** — найдёт самостоятельные feature, экспортные библиотеки и JSON запуска. Компилятор СППР не требуется.
- **Перехожу со старого KOT** — покажет существующие настройки и перенос поддерживаемых метаданных. UID и текст тестов сохраняются. Смена формата исходника выполняется отдельной конвертацией.

Проверка проекта читает файлы и показывает результат. Автоматический перенос метаданных приостановлен до применения плана. Обычные действия с группами и свойствами доступны и без мастера. Если найдены слишком большой каталог, конфликтующие данные или несохранённые исходники, мастер объяснит, что нужно исправить.

## Пути, профили и выполнение

У путей есть **Обзор…**. Файлы внутри выбранного проекта по возможности сохраняются относительным путём; установленные программы и внешние файлы — полным. Отмена выбора ничего не меняет. Библиотеки можно добавлять несколькими папками.

Для СППР в Конфигураторе сохраните обработку `СборкаТекстовСценариев` в отдельный файл `.epf`, например в папку `build` проекта. Здесь нужен файл обработки, а не выгрузка всей конфигурации `.cf`.

Версия каталога шагов Vanessa определяется по `docs/Changelog.md` рядом с выбранной `vanessa-automation.epf`. Её можно зафиксировать вручную в настройках подсказок. Это не обновляет саму Vanessa.

На шаге выполнения выберите **Пока только редактор** или **Подключить 1С и Vanessa**. Проверка окружения ещё не создаёт базу. Подготовка служебной базы и подключение начинаются после применения итогового плана; текущее состояние Vanessa видно в нижней строке VS Code. Если подключение отменено или не удалось, итоговый экран покажет это и предложит повторить только подключение; редактор при этом уже готов.

Мастер может создать отдельный профиль компиляции и запуска, сохранив существующие, либо использовать выбранный профиль без изменения его параметров. Итоговый экран перечисляет новые файлы, настройки и их области, а также переносимые метаданные. Существующие файлы не перезаписываются. Если для компиляции СППР ещё нужны параметры, после применения доступен переход к их редактору.

Локальное выполнение 1С сейчас рассчитано на Windows. На macOS/Linux доступны редактор, настройка проекта и работа с исходниками. В рабочей области с несколькими папками параметры записываются для выбранной папки; для мастера подготовки профиля сборки и выполнения откройте нужный проект в отдельном окне: существующие профили управляют общим корнем поиска тестов. Настройки VS Code, относящиеся ко всему окну, меняются в области «Рабочая область» или «Этот компьютер».

## Как менять настройки

Страница содержит восемь разделов и поиск по назначению или техническому имени. Левая навигация остаётся на месте, прокручивается правая форма.

1. Выберите папку проекта и область изменения.
2. Измените нужные значения. Это черновик; переходы между разделами его сохраняют.
3. Нажмите **Применить** или **Отбросить**. Перед записью проверяются тип, допустимые значения и внешние изменения.

**Сбросить в выбранной области** удаляет только переопределение этой области. Значение из другой области остаётся действующим. Источник и сброс появляются при наведении на поле или фокусе внутри него. Значок `i` открывает техническое имя и полное описание; подсказка доступна с клавиатуры и закрывается Escape.

**Отключённые проверки** выбираются из списка. Настройки совместимости со старыми проектами находятся под отдельным раскрытием. Длинные каталоги, платформы и профили открываются в существующем редакторе или нативных настройках; они сохраняют данные независимо от черновика страницы.

Если значение изменили в другом месте, KOT отметит конфликт. Можно оставить текущее значение и заново внести нужную правку. После частичной ошибки уже применённые значения не отправляются повторно.

При закрытии страницы с черновиком можно применить его, отбросить или оставить до перезагрузки KOT. Несохранённый ключ API не записывается в состояние страницы. После перезагрузки расширения применённые настройки читаются из VS Code; незавершённый мастер возобновляется для своей папки.
