# Блок: Diagnostics and Quick Fix

Для сценариев, процессов и их настроек KOT отмечает табуляцию в структурных отступах YAML как ошибку. Компилятор СППР считает уровни группами по четыре пробела. Быстрое исправление заменяет табуляцию пробелами в выбранном отступе или во всём файле. Табуляция внутри строковых значений, таблиц и текста сценария после корректного YAML-отступа сохраняется; обычные пробелы не считаются ошибкой.

## Задача блока

Показывать ошибки и предупреждения прямо в редакторе, с возможностью исправлять их одним действием.

## Проверки

### Ошибки

- Неизвестный шаг Gherkin.
- Неизвестный вызов вложенного сценария.
- Незакрытые блоки `If...EndIf`, `Do...EndDo`, `Try...EndTry` и `#Если...#КонецЕсли` с поддержкой русских аналогов. Циклы Vanessa при вставке в YAML адаптируются к `Do`/`Цикл`.
- Нарушение вложенности блоков, смешение языков открывающего/закрывающего слова, лишние и повторные ветки `Else`/`Except`. Проверка использует общий стек для runtime-блоков и препроцессора.
- Незакрытые блочные комментарии и многострочные строки; некорректные скобки/кавычки и отсутствие `Тогда` в условии препроцессора. Содержимое комментариев и многострочных строк не проверяется как шаги.
- Некорректная запись `Return`/`Возврат`; имя возвращаемого параметра проверяется по вызываемому сценарию.
- Незакрытые кавычки в строке.
- Лишние параметры у вызова сценария.

В `.feature` проверка синтаксиса поддерживает управляющие строки Vanessa `Try`/`Except`, `ElseIf`/`Else` и русские аналоги. Блоки задаются отступами, поэтому `EndTry` и другие закрывающие слова не требуются. Неизвестные строки, повреждённые таблицы и незакрытые многострочные строки сохраняют диагностику с исходными номерами строк.

### Предупреждения

- Недостающие параметры у вызова сценария.
- Неполные секции `ВложенныеСценарии` и `ПараметрыСценария`.
- Дубли значения `ДанныеСценария.Код` в разных сценариях.
- Вероятно пропущенные кавычки в аргументах шага/вызова.
- Запись `Result = ParentResult` означает получение результата; предупреждение о пропущенных кавычках для неё не показывается.
- Пустое или дефолтное описание сценария в `KOTМетаданные.Описание`.

## Quick Fix

- `Replace with ...` для неизвестных шагов/вызовов.
- `Maybe you meant` с набором релевантных вариантов.
- Добавление недостающих параметров вызова:
  - сразу всех;
  - по одному.
- `Fix all scenario issues` для файла:
  - замена табов;
  - выравнивание таблиц и параметров вызова;
  - перезаполнение `ВложенныеСценарии` и `ПараметрыСценария`.

## Режимы диагностики

1. Локальный: активный файл.
2. Связанные родительские сценарии: по цепочке вызовов вверх.
3. Глобальный scan по команде: `KOT - Scan workspace diagnostics` (`KOT - Выполнить сканирование диагностики по проекту`). Перед запуском показывается явное предупреждение о высокой нагрузке; сканирование идет по сценариям из текущего корня сценариев.

## Настройки блока

| Настройка | Назначение |
|---|---|
| `kotTestToolkit.diagnostics.ignoredCodes` | Скрывает выбранные виды диагностик по стабильному коду для пользователя, workspace или отдельной папки workspace |
| `kotTestToolkit.editor.checkRelatedParentScenarios` | Включает/выключает проверку связанных родительских сценариев |
| `kotTestToolkit.output.advancedLogging` | Более подробный лог диагностических операций |

Новые проверки структуры компилятора используют код `kotTestToolkit.compilerSyntax`. Незакрытые runtime-блоки сохраняют существующие коды `unclosedIf`, `unclosedDo`, `unclosedTry`.

Например, чтобы глобально разрешить значения без кавычек и пустое описание сценария:

```json
"kotTestToolkit.diagnostics.ignoredCodes": [
    "kotTestToolkit.missingQuotes",
    "kotTestToolkit.defaultDescription"
]
```

Предупреждения `kotTestToolkit.compilerFormat` проверяют поднабор YAML предоставленного компилятора СППР: кавычки скаляров, точный маркер `|`, структурные отступы по четыре пробела, комментарии вне многострочного содержимого и расширение `.yaml`. Это проверка совместимости с обработкой; корректный общий YAML может не читаться её собственным парсером. Соседние `*.kot.yml` и общие YAML-настройки проекта исключены. Исходники автоматически не переписываются.
