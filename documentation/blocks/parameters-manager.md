# Параметры компиляции и запуска

Этот менеджер задаёт, **как** KOT собирает и запускает тесты. Параметры отдельного сценария задают, **какие данные** он проверяет. Это разные настройки.

Откройте менеджер из меню KOT. Профили позволяют хранить несколько окружений и выбирать нужное перед сборкой; переключение профиля не требует переписывать исходники.

## Три части профиля

| Часть | Что задаёт |
|---|---|
| Параметры СППР | Каталоги сценариев/процессов, результат сборки, каталог эталонных баз, фильтры и режимы компилятора |
| Дополнительные параметры Vanessa | Параметры выполнения: библиотеки, язык генератора, отчёты и другие поддерживаемые значения |
| GlobalVars | Начальные значения сохранённого контекста Vanessa |

Значения могут сохраняться независимо от черновика общей страницы настроек KOT. Проверяйте активный профиль перед изменением.

## Минимальная проверка СППР

- `ScenarioFolder` — каталог сценариев; при отдельном расположении процессов проверьте `ProcessFolder`.
- `FeatureFolder` — каталог собранных feature и JSON.
- `ModelDBSettings` — файл каталога эталонных баз, когда он требуется компилятору.
- Режимы создания JSON и отчётов, а также фильтры отбора.

`TestFolder` — поддерживаемый общий алиас с приоритетом для обоих корней. Не добавляйте его, если намеренно используете разные каталоги сценариев и процессов.

## Дополнительные параметры Vanessa

Ключи выбираются из каталога с описаниями, значения имеют ожидаемый тип. Список добавления не предлагает уже добавленные параметры. Поддерживаются известные русские/английские эквиваленты и собственные ключи.

Кнопки импорта/экспорта помогают перенести JSON. Важна разница между числом, логическим значением и строкой: `false` не равно строке `"false"`.

`Libraries` компилятора использует разделитель `|`; собственная библиотека Vanessa добавляется автоматически. Пользовательские библиотеки подключайте явно. Обнаружение параметров по исходникам выбранной Vanessa точнее встроенного резервного каталога.

## Приоритеты

Компиляция создаёт исходный JSON. KOT формирует итоговые параметры с учётом дополнительных значений, их приоритета и служебных полей выбранного способа запуска. В активном MCP-сеансе не все эти значения можно применить заново.

Если результат отличается от ожидаемого, откройте исходный и итоговый JSON через действия теста и сравните нужный ключ. Точные правила — [справочник компилятора и запуска](../technical/compiler.md).
