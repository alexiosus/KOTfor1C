# Свойства теста

Откройте сценарий, процесс или feature: справа появятся **Свойства теста**. Панель следует за активным документом; **булавка** закрепляет выбранный тест. Команда открытия свойств также доступна из Менеджера тестов и Библиотеки.

## Основные действия

В шапке находятся **Сохранить → Запустить → Избранное → Закрепить**. Доступность запуска зависит от вида теста и наличия необходимого результата сборки или JSON.

- **Сохранить тест** сохраняет правки исходника; для feature + meta охватывает оба документа.
- **Звезда** добавляет тест в личное избранное.
- **Булавка** оставляет свойства этого теста при переходе на другие вкладки.
- **Свернуть разделы** уменьшает объём формы, не меняя файл.

Изменения остаются правками обычных документов VS Code: доступны Undo и сохранение. Статус панели помогает отличить несохранённый текст от уже записанных изменений.

## Что редактируется

| Вид теста | Поля и разделы |
|---|---|
| Сценарий СППР | Шапка, метаданные KOT, параметры, вложенные сценарии, теги, настройки запуска и файлы |
| Процесс СППР | Шапка, параметры, теги, шаги сценариев/подпроцессов и настройки запуска |
| Самостоятельная feature | Заголовок, описание, теги, группа, JSON запуска, сценарии и структурные блоки |
| Собранная feature | Свойства однозначно найденного исходника и действия с результатом сборки |

В паре СППР **Open feature** открывает текст, **Open YAML** — `meta.yaml`. Кнопка **Преобразования** предлагает доступные изменения формата и роли.

## Добавить содержимое

У списка сценариев feature кнопка **+** создаёт обычный сценарий или Scenario Outline. Язык берётся из файла; после вставки можно продолжить писать первый шаг. Background, Variables, импорты и другие блоки находятся в действиях feature.

Параметры СППР показывают значения по умолчанию и использование в тексте. Настройки запуска редактируются отдельным разделом. На вкладке **Файлы** можно добавлять вложения, открывать каталог и вставлять имена файлов в шаги.

Если панель перестала следовать за вкладками, сначала проверьте булавку. Для неоднозначного определения выберите конкретный элемент в Библиотеке.
