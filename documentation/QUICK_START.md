# Первый тест в KOT

Цель этого руководства — открыть понятный пример, изменить его и выбрать следующий шаг. Полностью настраивать 1С для знакомства не требуется.

## Установить расширение

Установите [KOT for 1C](https://marketplace.visualstudio.com/items?itemName=AlexeyEremeev.kot-test-toolkit) в VS Code **1.106 или новее**. Откройте папку проекта и значок KOT на левой панели. Это руководство относится к **3.0.0**; проверьте установленную версию.

В палитре команд найдите **KOT: Настроить проект**. Название команды может быть на английском — **Set up project**. Мастер предлагает четыре маршрута: с нуля, существующий СППР, существующая Vanessa и прежняя версия KOT.

## Попробовать без 1С

1. В мастере нажмите **Открыть копию учебной мастерской** и выберите родительскую папку.
2. KOT создаст отдельную папку `KOT-workshop` и откроет её в новом окне.
3. Откройте `tests/sppr/01-first-scenario/scen.yaml`.
4. В свойствах справа найдите параметр **Customer** и измените его значение по умолчанию. Нажмите **Сохранить тест**.
5. В тексте поставьте каретку на вызов `And I prepare workshop customer` и нажмите **F12**. Откроется вложенный сценарий.
6. Найдите шаг в Библиотеке и вставьте его в редактор.

**Результат:** вы увидели связь текста, параметров и повторного использования. Действия в редакторе не требуют запуска 1С. Продолжение — [упражнения мастерской](../examples/kot-workshop/README.md).

## Проект СППР

1. Выберите маршрут **У меня проект СППР** и выполните поиск файлов.
2. На шаге редактора проверьте найденный каталог сценариев, библиотеки, язык новых сценариев и профиль. Формат существующих файлов мастер не меняет.
3. Выберите **Пока только редактор**, если хотите сначала изучить проект.
4. Для компиляции на Windows укажите платформу 1С и `.epf` обработки `СборкаТекстовСценариев`, сохранённой из вашей конфигурации СППР. Для выполнения укажите Vanessa.
5. Изучите итоговый план и примените его.
6. В Менеджере тестов отметьте главный сценарий или процесс и нажмите **Скомпилировать / Compile**. После успешной сборки откройте полученную feature или запустите её.

Главный сценарий имеет отдельную **настройку запуска**. Вложенный сценарий без неё не является самостоятельной строкой сборки. Процессы устроены аналогично.

**Если компилятор ещё не готов:** редактор можно использовать сразу; [параметры компиляции](blocks/parameters-manager.md) заполните позже.

## Проект Vanessa

1. Выберите маршрут **У меня проект Vanessa** и найдите существующие feature.
2. Проверьте каталог исходников и библиотек. Самостоятельные тесты появятся в соответствующей секции Менеджера тестов.
3. Откройте feature. В свойствах задайте заголовок и теги; при необходимости добавьте сценарий кнопкой **+**.
4. Выберите или создайте **JSON запуска** из активного профиля.
5. На Windows нажмите **Подключить Vanessa**. Можно подготовить управляемый сеанс или подключиться к уже работающему совместимому сеансу.
6. Запустите тест кнопкой **Run**. Для отдельного обычного шага поставьте каретку на строку и нажмите **F11**.

**Результат:** выполняется feature Vanessa без компилятора СППР. Подробнее — [самостоятельные feature](blocks/standalone-features.md) и [пошаговое выполнение](blocks/vanessa-control.md).

## Проект старой версии KOT

Выберите маршрут перехода со старого KOT. Поиск покажет найденные исходники и метаданные, а итоговый экран — предлагаемые изменения. Проверьте Git diff после применения. Переход на `feature + meta.yaml` — отдельное преобразование; мастер не меняет формат всех тестов автоматически.

## Где искать следующие действия

| Действие | Где находится |
|---|---|
| Параметры и настройки выбранного теста | Свойства справа |
| Выбор тестов для компиляции | Менеджер тестов слева |
| Шаги и вложенные сценарии | Отдельный значок Библиотеки слева |
| Базы и клиенты | Секция Информационные базы |
| Состояние Vanessa | Нижняя строка VS Code |
| Настройки расширения | Меню KOT → Настройки расширения |

Если что-то не появилось или не запустилось, откройте [решение проблем](troubleshooting.md). Все возможности сгруппированы в [руководстве](README.md).
